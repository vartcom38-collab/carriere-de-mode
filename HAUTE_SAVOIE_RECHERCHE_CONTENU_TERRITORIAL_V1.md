# HAUTE-SAVOIE — RECHERCHE & CADRAGE TERRITORIAL V1

Branche : `territoires-france`  
Département : Haute-Savoie (74)  
Date de cadrage : 2026-09-10

## Principe gameplay

La Haute-Savoie ne doit jamais être résumée à « station de ski chic ». Le département combine lac, villes, thermalisme, patrimoine rural, artisanat, industrie de précision, agriculture/alpage, sports d'hiver, alpinisme, hôtellerie, clientèle internationale, photographie, culture et villages touristiques.

## Pôles structurés

### Annecy
Identité gameplay : lac / élégance / design urbain / cérémonie / éditorial / clientèle créative.

### Chamonix-Mont-Blanc
Identité gameplay : alpinisme / expédition / performance / tests terrain / luxe sportif / clientèle internationale.

### Le Grand-Bornand
Base documentaire forte : Maison du patrimoine, culture agropastorale, artisanat et Fête de la laine, de la soie et du tissage. L'édition 2026 présente matières premières issues d'élevage, vêtements et accessoires tissés, tricotés, crochetés, feutrés, teints et réalisés en soie, en pièces uniques ou petites séries.
Gameplay : laine / soie / tissage / maille / feutre / teinture / alpage / transmission.

### Châtel
Gameplay : station-village du Chablais / frontière suisse / hiver / petites capsules / hôtellerie / après-ski.

### Megève
Gameplay : luxe alpin / patrimoine / hôtellerie / soirée / ski chic / clientèle premium. Les événements patrimoniaux et photographiques réels servent de références ponctuelles ; les éditions futures du jeu restent générées/fictives.

### Évian-les-Bains
Base documentaire : thermalisme, patrimoine architectural, Buvette Cachat, jardins et Léman.
Gameplay : villégiature / élégance / bien-être / soirée / photographie / clientèle internationale.

### Thonon-les-Bains
Gameplay : Léman / patrimoine / ateliers / clientèle locale / accessoires / photo / collaborations artisanales.

### Morzine
Base documentaire 2026-2027 : saison culturelle Morzine en Scène, spectacles de septembre 2026 à mars 2027.
Gameplay : glisse / village vivant / sportswear / culture / événement / réparation.

### Avoriaz
Gameplay : architecture graphique / snowboard / culture ride / performance / image futuriste / film et photo.

### La Clusaz
Base documentaire : agenda annuel, marché, patrimoine et activités locales.
Gameplay : Aravis / ski / artisanat / maille / cuir / clientèle saisonnière.

### Cluses / vallée de l'Arve
Base documentaire majeure : fabrication de petites pièces métalliques depuis environ trois siècles ; relation historique avec l'horlogerie suisse ; école d'horlogerie créée en 1848 ; décolletage devenu industrie centrale au XXe siècle.
Gameplay : précision métal / boutons et pièces / fermoirs / hardware / accessoires / bijou / collaboration industrie-mode / B2B.

### Sallanches
Base documentaire 2026 : Montagn'Arts Photo et Journées du patrimoine accueillant les Métiers d'art des Savoie.
Gameplay : photographie / métiers d'art / ville de vallée / Mont-Blanc / collaborations.

### Saint-Gervais-les-Bains
Base documentaire : thermes du Mont-Blanc ; patrimoine vernaculaire, médiéval, thermal, baroque et agricole ; politique culturelle active.
Gameplay : thermalisme / bien-être / patrimoine / culture / élégance de montagne / Mont-Blanc.

### Samoëns
Base documentaire forte : tradition des Frahans, tailleurs de pierre, maçons, bâtisseurs et sculpteurs ; parcours de pierre sculptée ; patrimoine architectural ; jardin botanique alpin.
Gameplay : pierre / sculpture / motifs / volumes / scénographie / accessoire / botanique / village alpin.

### Yvoire
Gameplay prudent : village lémanique patrimonial / végétal / tourisme / cérémonie / éditorial / accessoires. Approfondissement documentaire à refaire avant toute intégration d'un événement réel spécifique.

## Règle de vérité

1. Les lieux, patrimoines et événements explicitement documentés sont des références réelles.
2. Les personnages, clientes, briefs, commandes, secrets et opportunités générés par les banques sont fictifs.
3. Une édition réelle datée 2026 ne doit jamais être automatiquement présentée comme réelle en 2027, 2028, etc.
4. Les événements futurs récurrents du runtime sont des familles de gameplay fictionnelles ou des interprétations évolutives.
5. La Haute-Savoie doit garder des contrastes : lac ≠ Chamonix ≠ Aravis ≠ Arve industrielle ≠ Chablais ≠ stations premium.
