# AURA — reprise Nîmes-parité

Branche de travail : `nimes-parity-territoires`

## Définition de terminé

Un département n'est pas terminé parce que ses marqueurs existent. Il faut :

- grandes villes + villes secondaires + villages utiles ;
- patrimoine, musées, paysages et points de vue ;
- matières / merceries / textile ;
- artisans et savoir-faire ;
- brocantes / pièces uniques / événements temporaires ;
- cafés et lieux sociaux ;
- archives / bibliothèques / fonds documentaires ;
- studios / photo / image ;
- transport et voyage ;
- hôtels / chez-moi temporaire dans les pôles de séjour ;
- événements saisonniers ;
- figures culturelles documentaires pouvant ouvrir une piste de collection ;
- personnages fictifs persistants clairement identifiés ;
- rencontres temporaires ;
- rumeurs, affiches, invitations ;
- conséquences Book / Atelier / Agenda / relations / carrière ;
- revisites et variations jour / heure / saison ;
- QA interface : aucun retour automatique à la fiche générique si un template spécialisé existe.

## Templates communs

- patrimoine / musée / monument : V1 branché
- mercerie / matières : V1 branché
- brocante / vintage : V1 branché

- événement : V1 branché

- rumeur : à créer/brancher comme billet éditorial
- affiche : à créer/brancher comme objet graphique
- invitation : à créer/brancher comme carton / pass / RSVP
- rencontre : à relier au système personnages / visual novel

## Règle figures réelles

Une personnalité réelle est une référence documentaire : lieu, archive, musée, époque, silhouette, objet, œuvre, scène ou imaginaire. Elle peut ouvrir une recherche ou une collection. Elle n'est jamais utilisée comme PNJ fictif qui invente des propos, une relation ou une approbation de Marion.
