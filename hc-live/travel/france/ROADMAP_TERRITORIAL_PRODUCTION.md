# Roadmap territorial de production — France

Objectif : construire le monde du jeu sans trous, avec le même niveau d’exigence pour chaque région, département, ville, village et lieu.

## Règle de production

On termine un territoire avant de passer au suivant. Pour chaque lieu réel : recherche officielle/institutionnelle, vraies images ou références visuelles quand elles existent, histoire et anecdotes, objets/œuvres/détails, lecture mode, tags, déblocages Book/Atelier, visuels associés, prompts futurs, gameplay, rencontres et revisites. Pour les éléments purement créatifs : ils sont clairement présentés comme interprétations de styliste.

Aucun déblocage Atelier permanent ne doit être considéré comme terminé sans : visuel exploitable, titre, description, provenance, usage, tags, prompt futur et stockage dans la banque Atelier/Book.

## Ordre de production retenu

On conserve Occitanie comme région pilote, puisque Gard/Nîmes est déjà avancé. On termine d’abord le Gard, puis les autres départements d’Occitanie par ordre de numéro. Ensuite, on passe aux autres régions françaises par ordre alphabétique.

## Definition of Done — Département

Un département n’est pas "fini" parce qu’on a posé 5 pins. Il doit avoir :

- carte et géographie de gameplay ;
- villes et villages majeurs + sélection de petites communes intéressantes ;
- monuments, musées, patrimoine, architecture ;
- nature, paysages, points de vue ;
- merceries, tissus, mode, friperies, brocantes, marchés ;
- artisans et savoir-faire ;
- bibliothèques, archives, lieux culturels ;
- gastronomie utile à l’ambiance et au social ;
- lieux secrets fictifs clairement séparés du réel ;
- rencontres et personnages persistants ;
- événements et saisons ;
- missions/opportunités ;
- photos et galeries ;
- pages Book riches ;
- déblocages Atelier visuels ;
- tags transversaux ;
- suggestions Instagram/Stories ;
- revisites et couches de carrière longue.

## Definition of Done — Ville / Village

Chaque ville/village retenu doit avoir : identité, histoire, carte locale, lieux cliquables, galerie, personnages, activités, inspirations, Book, Atelier, téléphone, événements, secrets et revisites.

## Definition of Done — Lieu

Chaque lieu doit au minimum fournir :

1. photo ou visuel principal pertinent ;
2. galerie si disponible ;
3. paragraphe de présentation ;
4. histoire développée ;
5. anecdotes ;
6. objets, œuvres, sculptures ou détails lorsque pertinent ;
7. architecture / matière / lumière / forme ;
8. lecture mode longue ;
9. palette ;
10. matières ;
11. motifs ;
12. silhouettes / accessoires / bijoux si pertinent ;
13. 2 à 8 déblocages gameplay selon richesse ;
14. visuel de chaque déblocage important ;
15. texte d’usage Atelier ;
16. prompt futur pour génération de croquis ;
17. tags ;
18. ajout Book ;
19. ajout Atelier ;
20. contenu social ;
21. source(s) documentaire(s) ;
22. couches de revisite / rencontres / secrets.

## Principe de densité

Tout ne doit pas être disponible au même moment. Le contenu culturel fondamental d’un grand lieu est accessible dès la première visite. Les revisites servent surtout aux rencontres, secrets, variations saisonnières, opportunités, missions, objets rares et nouvelles lectures liées à l’évolution de carrière.

## Règle de liaison

Chaque nouveau contenu doit nourrir au minimum deux systèmes parmi : Carte, Book, Atelier, Téléphone, Instagram, Agenda, Relations, Missions, Réputation, Portfolio.
