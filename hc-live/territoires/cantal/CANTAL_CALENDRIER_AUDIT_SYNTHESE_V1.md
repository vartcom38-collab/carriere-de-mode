# HAUTE COUTURE LIVE — CANTAL — CALENDRIER / AUDIT / SYNTHÈSE V1

## CALENDRIER STRUCTUREL
Janvier-février : montagne, vêtements chauds, tourisme hiver, réparations, clientèle locale.
Mars-avril : reprise mariages, marchés, patrimoine, préparations saison culturelle.
Mai-juin : événements de villages, tourisme, shootings, clientèle cérémonielle.
Juillet : Salers, marchés, patrimoine, événements, Champ libre ! avant Festival Aurillac.
Août : Festival international d’Aurillac, tourisme maximal, spectacles, besoins urgents, population temporaire.
Septembre : patrimoine, vide-greniers, marchés, retour clientèle locale, événements de Murat/Salers.
Octobre-novembre : rentrée culturelle, vêtements de transition/hiver, artisanat et clientèle régulière.
Décembre : fêtes, marchés, cérémonie, hôtellerie, montagne.

Règle : les dates réelles 2026 sont des références. Les années futures sont simulées à partir de familles d’événements avec variation et mémoire anti-redondance.

## CHANGEMENT DU MONDE 20–30 ANS
- transmission ou départ d’une patronnière/accessoiriste ;
- manufacture qui change de gamme ou de direction ;
- jeune créateur qui ouvre puis déplace son atelier ;
- festival qui change de focus ;
- compagnie autrefois émergente devenue reconnue ;
- hôtel rénové ou fermé ;
- station de montagne dont la saison évolue ;
- nouvelles contraintes climatiques ;
- ancienne cliente qui revient avec enfant/petite-fille ;
- marchés dont certains exposants disparaissent ;
- nouvel artisan ou commerce temporaire ;
- fonds patrimonial nouvellement numérisé ;
- lieu culturel réorganisé.
