# HAUTE COUTURE LIVE — ALLIER (03) — MOULINS — CHECKLIST VILLE V1

Référentiel éditorial : Nîmes ville test + checklist territoriale officielle.
Branche : territoires-france.

## 1 — ADN DE VILLE

Moulins doit être un pôle exceptionnel pour :
- costume de scène ;
- patrimoine ducal ;
- scénographie ;
- conservation ;
- spectacle ;
- recherche ;
- archives ;
- formation / démonstration de savoir-faire ;
- photographie nocturne ;
- tourisme culturel.

La ville ne doit pas être réduite au CNCS : le CNCS est le cœur mode/spectacle, mais le gameplay doit aussi circuler entre théâtre, patrimoine, centre ancien, musées, parcours lumineux, Yzeure et lieux sociaux.

## 10 — RUMEURS / SECRETS

Rumeurs possibles :
- une ancienne costumière accepte parfois de montrer ses carnets ;
- un atelier invité cherche une aide ponctuelle ;
- une réserve documentaire contient une référence inattendue ;
- une ancienne cliente possède une pièce de spectacle familiale ;
- un photographe connaît un accès nocturne intéressant ;
- un artisan intervient seulement pendant certaines manifestations.

Secrets :
- contact professionnel discret ;
- fonds documentaire précis ;
- pièce d’étude rare ;
- recommandation d’un régisseur ;
- opportunité de résidence ;
- ancienne relation entre deux professionnels.
