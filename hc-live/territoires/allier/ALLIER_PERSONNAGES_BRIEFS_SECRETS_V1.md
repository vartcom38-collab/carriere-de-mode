10. Cliente de longue date qui révèle une histoire familiale liée à un vêtement.
11. Ancien concurrent devenu décideur culturel.
12. Collection privée fictive visible uniquement sur recommandation.

Chaque secret possède : condition, niveau de relation, saison éventuelle, rareté, conséquence, possibilité de manquer définitivement ou temporairement.

# 8 — MÉMOIRE / REVISITES

Les personnages doivent se souvenir :
- d’un retard ;
- d’une tenue réussie ;
- d’un refus ;
- d’une recommandation ;
- d’un prix jugé juste ou excessif ;
- d’une urgence sauvée ;
- d’une collaboration difficile ;
- d’un cadeau ou service ;
- du fait que Marion a déménagé sans couper son réseau.

Les relations peuvent évoluer : cliente → habituée → amie ; concurrent → collègue ; jeune créateur → partenaire ; professionnelle → retraitée → mentor ; cliente → mère d’une future cliente.
