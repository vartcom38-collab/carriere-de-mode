# HAUTE COUTURE LIVE — ALLIER — PÔLES SECONDAIRES V1

Référentiel : checklist territoriale officielle + gabarit éditorial Nîmes ville test.

Pôles traités : Bourbon-l’Archambault, Néris-les-Bains, Charroux, Souvigny, Lapalisse.

---

# 1 — BOURBON-L’ARCHAMBAULT

## Identité
Ville thermale et historique liée à la maison de Bourbon. Elle apporte une tonalité plus intime et patrimoniale que Vichy : soins, séjour, château, mémoire dynastique, petite ville.

## Gameplay
- clientèle de cure ;
- cérémonies familiales ;
- recherches historiques ;
- petites commandes de séjour ;
- vêtements confortables et élégants ;
- relations longues avec clientèle fidèle ;
- découverte de détails architecturaux / héraldiques comme DESIGN_REFERENCE uniquement.

## FICTION GAMEPLAY
Personnages : curiste régulière, hôtelière, antiquaire, médiatrice patrimoine, cliente locale, photographe.

Briefs : tenue de cure, transformation d’un manteau ancien, tenue de dîner, ensemble mère/fille, shooting patrimonial, capsule de voyage.

Secrets : recommandation d’une cliente ancienne, petite collection privée fictive, lot textile lors d’une succession, salon d’hôtel utilisable sur invitation.

---

# 2 — NÉRIS-LES-BAINS

## Identité
Station thermale plus petite, élégante et calme, avec potentiel de séjour, patrimoine thermal, parc, sociabilité saisonnière.

## Gameplay
- vêtements de séjour ;
- confort / mouvement ;
- élégance discrète ;
- clientes régulières ;
- mariages / réceptions de petite échelle ;
- photographie de parc / architecture.

## FICTION GAMEPLAY
Personnages : kiné fictive, habituée des cures, responsable de pension, photographe, fleuriste événementielle, commerçante.

Briefs : robe souple, ensemble de voyage, retouche express, tenue de réception, vestiaire capsule de trois pièces.

---

# 3 — CHARROUX

## Identité
Village patrimonial et artisanal, fort potentiel de promenade, tourisme, photographie, artisanat, petites adresses et saisonnalité.

## Gameplay
- inspirations pierre / enseignes / portes / textures ;
- artisanat ;
- clientèle touristique ponctuelle ;
- brocante / objets anciens si événements réels vérifiés ;
- shooting éditorial ;
- petites collaborations créatives.

## Règle
Ne pas transformer automatiquement le village en “village de mode”. La mode vient de l’observation, des rencontres et des usages réels.

## FICTION GAMEPLAY
Personnages : artisan, galeriste, brocanteuse, photographe, propriétaire de chambre d’hôtes, jeune créatrice.

Secrets : cour intérieure, adresse d’artisan, lot ancien, recommandation, exposition temporaire.

---

# 4 — SOUVIGNY

## Identité
Pôle patrimonial et religieux lié à l’histoire clunisienne et bourbonnaise. Fort pour archives, architecture, cérémonial, musique / événements patrimoniaux si vérifiés.

## Gameplay
- recherche historique ;
- vêtements cérémoniels comme étude documentaire ;
- architecture / sculpture / pierre comme références ;
- photographie ;
- événements culturels ;
- collaborations patrimoniales fictives.

## Règle sensible
Le patrimoine religieux ou funéraire n’est jamais réduit à une récompense esthétique automatique.

## FICTION GAMEPLAY
Personnages : médiatrice, historienne, photographe, organisateur culturel, habitante âgée, restauratrice fictive du patrimoine.

---

# 5 — LAPALISSE

## Identité
Petite ville patrimoniale structurée autour de son château, de l’axe de passage et d’événements historiques / culturels à revalider année par année.

## Gameplay
- clientèle de passage ;
- cérémonies ;
- shooting patrimoine ;
- événements ;
- liens routiers avec autres pôles ;
- petite réputation locale pouvant devenir relais vers Vichy / Moulins.

## FICTION GAMEPLAY
Personnages : organisatrice événementielle, commerçante, photographe, cliente locale, hôtelière, collectionneur fictif.

---

# 6 — LOGIQUE COMMUNE DES PÔLES SECONDAIRES

Ces villes ne doivent pas recevoir artificiellement autant de contenu qu’un grand pôle. Leur force vient de :
- quelques lieux très identitaires ;
- personnages persistants ;
- événements saisonniers ;
- petites chaînes de recommandation ;
- revisites ;
- secrets ;
- missions spécifiques que Moulins / Vichy / Montluçon ne proposent pas.

Le joueur doit avoir une vraie raison d’y revenir sans que chaque commune devienne une capitale de mode.

---

# 7 — CONNEXIONS

- Bourbon-l’Archambault ↔ Moulins ;
- Néris-les-Bains ↔ Montluçon ;
- Charroux ↔ Vichy / secteur Saint-Pourçain ;
- Souvigny ↔ Moulins ;
- Lapalisse ↔ Vichy / Est de l’Allier.

Les voyages créent des réseaux professionnels, jamais un changement automatique de résidence.
