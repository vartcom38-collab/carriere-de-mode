# HAUTE COUTURE LIVE — ALLIER (03) — COMPLÉMENTS RÉELS DE PRÉCISION V1

Référentiel : gabarit éditorial Nîmes ville test + checklist territoriale officielle.

Principe absolu :
- les faits, lieux, structures et figures réels sont documentés comme contexte ;
- les interactions narratives complexes passent par des personnages FICTION GAMEPLAY ;
- aucune personne réelle ne devient automatiquement cliente, mentor, employeur ou partenaire de Marion.

---

# 1 — MOULINS : ARCHIVES, HÔTELLERIE, PATRIMOINE URBAIN

## Archives municipales de Moulins
Rôle : recherche urbaine, sociale et architecturale.

Contenus réellement documentés :
- délibérations anciennes ;
- comptes de ville ;
- registres paroissiaux ;
- cadastre napoléonien ;
- recensements ;
- dossiers de bâtiments communaux ;
- cartes postales anciennes ;
- plans anciens.

Gameplay :
- recherche avant projet patrimonial ;
- évolution d’un quartier ;
- retrouver l’histoire d’un bâtiment ;
- vérifier une adresse ancienne ;
- nourrir Book / DESIGN_REFERENCE / BOOK_RESEARCH.

Pas d’auto-récompense après consultation.

## Rue de Paris / rue de Bourgogne / hôtels particuliers
Rôle : lecture des façades, cours cachées, architecture élitaire, ferronnerie, proportions, détails.

Le parcours réel de visites guidées 2026 montre que certains accès sont ponctuels et limités : bonne base pour la rareté saisonnière et les revisites.

Gameplay :
- shooting architecture ;
- palette / motif / proportion ;
- rencontre temporaire pendant visite ;
- rumeur sur cour habituellement fermée ;
- invitation rare via réseau culturel.

## Hôtellerie significative
Acteurs réels identifiés via l’office de tourisme :
- Mercure Moulins Centre – Hôtel de Paris ;
- Hôtel Le Clos de Bourgogne ;
- autres hôtels à hiérarchiser selon usage réel.

Utilité gameplay :
- clientèle professionnelle de passage ;
- réception ;
- essayage discret ;
- rendez-vous presse ;
- séjour lié au CNCS / théâtre / patrimoine.

Règle : l’hôtel n’est pas une mission en soi ; il augmente seulement certains profils de passage et probabilités de rencontre.

# 2 — VICHY : ARCHIVES ET MÉMOIRE DE LA VILLE THERMALE

## Archives municipales de Vichy
Les fonds communaux remontent aux XVIe–XVIIe siècles.

Axes utiles :
- administration communale ;
- propriétés communales ;
- eaux ;
- édifices ;
- travaux publics ;
- voirie ;
- patrimoine thermal et évolution urbaine à rechercher selon fonds.

Gameplay :
- suivre la transformation d’une ville thermale ;
- histoire d’un hôtel ou équipement ;
- recherche d’une adresse ancienne ;
- évolution de quartier ;
- documentation d’un événement ancien.

Sorties possibles : BOOK_RESEARCH / DESIGN_REFERENCE / PALETTE_REFERENCE.

# 3 — MONTLUÇON : FIGURES HISTORIQUES ET MÉMOIRE LOCALE

La Ville de Montluçon maintient un corpus de figures illustres liées à l’histoire locale.

Exemple documenté :
- Louis II de Bourbon, figure majeure de l’histoire bourbonnaise et de Montluçon.

Usage gameplay :
- uniquement comme référence historique / patrimoniale ;
- jamais comme personnage interactif contemporain ;
- peut nourrir une exposition, un cours, une visite, un projet de recherche ou une commande culturelle FICTION GAMEPLAY.

À compléter au fil des sources avec :
- artistes ;
- musiciens ;
- industriels ;
- personnalités culturelles ;
- figures liées au patrimoine ou au spectacle.

# 5 — PHOTOGRAPHIE / STUDIOS / CRÉATIFS

État : inventaire réel encore partiel.

Règle de production :
- conserver les photographes réels uniquement comme contexte si leur activité est vérifiée ;
- pour les arcs mode récurrents, utiliser des personnages/studios FICTION GAMEPLAY ancrés dans les villes ;
- ne pas attribuer une spécialisation mode à un photographe réel sans source explicite.

Besoins prioritaires :
- 2–3 studios réels à Moulins ;
- 2–3 studios réels à Vichy ;
- 2–3 studios réels à Montluçon ;
- coiffeurs/maquilleurs seulement si vraie pertinence créative documentée.

---

# 6 — MERCERIES / TISSUS / FOURNITURES

État : inventaire encore incomplet à l’échelle départementale.

Règle :
- ne pas remplir artificiellement chaque ville ;
- distinguer fourniture courante / matériau spécialisé / événement temporaire / seconde main ;
- utiliser les Puces Couturières et rendez-vous de seconde main comme alternatives réelles quand le tissu commercial permanent est faible.

Gameplay :
- matière courante disponible sans rareté excessive ;
- pièces rares via événement ;
- fournitures spécialisées via réseau ou déplacement ;
- stock variable selon saison et commerce.

---

# 7 — CAFÉS / RESTAURANTS / LIEUX SOCIAUX

Règle héritée de Nîmes : un lieu social n’est retenu que s’il a une vraie fonction gameplay.

Fonctions acceptables :
- rendez-vous professionnel ;
- rencontre récurrente ;
- clientèle de passage ;
- lieu d’observation ;
- adresse liée à un événement ;
- réception / tourisme / patrimoine.

Moulins, Vichy et Montluçon devront privilégier une petite sélection de lieux identitaires plutôt qu’un catalogue.

# 10 — STATUT

Cette passe ferme les principaux manques de précision documentaire sans transformer l’Allier en annuaire.

Restent comme enrichissements non bloquants :
- davantage de fournisseurs textiles permanents vérifiés ;
- davantage de studios photo réels ;
- quelques lieux sociaux réellement distinctifs ;
- banque plus large de figures locales sourcées.

Ces manques ne bloquent plus une intégration V1 si les interactions passent par les personnages FICTION GAMEPLAY déjà prévus.
