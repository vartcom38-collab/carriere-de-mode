# HAUTE COUTURE LIVE — ALLIER (03) — CHANGEMENT DU MONDE 20–30 ANS — V1

Référentiel : checklist territoriale officielle + gabarit Nîmes.

Objectif : l’Allier ne doit jamais rester figé. Un lieu connu à 22 ans peut avoir changé quand Marion revient à 35, 45 ou 55 ans.

---

# 1 — TYPES DE CHANGEMENT

- retraite ;
- transmission ;
- fermeture ;
- ouverture ;
- déménagement d’atelier ;
- changement de propriétaire ;
- changement de programmation ;
- rénovation ;
- création d’un nouveau festival ;
- disparition d’un événement ;
- nouvel usage d’un bâtiment ;
- nouvelle exposition ;
- nouveau commerce ;
- nouvelle génération de clientèle ;
- mutation d’un quartier ;
- arrivée d’un concurrent ;
- changement dans les habitudes touristiques ;
- nouvelle desserte ou changement d’accessibilité.

---

# 2 — MOULINS

Scénarios procéduraux :
- jeune designer rencontré à la Maison des Métiers d’Art devient professionnel reconnu ;
- un costumier fictif prend sa retraite ;
- un atelier se transmet ;
- nouvelle exposition temporaire bouleverse les références disponibles ;
- un ancien contact du spectacle devient programmateur ;
- une ancienne création de Marion entre dans une exposition fictive ;
- une boutique de centre-ville ferme puis est remplacée ;
- un fonds privé de patrons devient accessible après plusieurs années.

---

# 3 — VICHY

- ancienne cliente de cure revient avec sa fille ou petite-fille ;
- hôtel fictif change de standing ;
- organisatrice de congrès devient directrice d’un équipement ;
- nouvelle génération de clientes internationales ;
- travaux modifient temporairement accès / shootings ;
- un événement patrimonial annuel change de thème ;
- un concurrent local monte en gamme ;
- une adresse de seconde main disparaît puis un nouveau lieu ouvre ailleurs.

---

# 4 — MONTLUÇON

- atelier de couture change de main ;
- musicien devient programmateur ;
- jeune créateur upcycling ouvre un lieu fictif ;
- fermeture d’une boutique provoque liquidation/stock temporaire ;
- patrimoine industriel restauré ou rendu accessible ponctuellement ;
- ancien vêtement de travail revient via succession ;
- photographe concert change de métier mais garde son réseau.

---

# 5 — PÔLES SECONDAIRES

## Bourbon / Néris
- clientèle thermale vieillit et se renouvelle ;
- établissement rénové ;
- petite adresse familiale transmise ;
- événement disparaît puis renaît quelques années plus tard.

## Charroux
- artisan transmet sa boutique ;
- ancien commerce devient atelier ;
- tourisme plus ou moins intense selon périodes.

## Souvigny
- nouveau programme de recherche ;
- restauration patrimoniale ;
- exposition temporaire ;
- changement d’accès à certains fonds.

## Lapalisse
- lieu de réception change de propriétaire ;
- nouvelle clientèle mariage ;
- photographe ou décoratrice s’installe ou part.

---

# 6 — ÉVOLUTION DES PERSONNAGES

Chaque personnage persistant peut :
- changer de poste ;
- se marier / divorcer / avoir une famille ;
- déménager ;
- revenir ;
- prendre sa retraite ;
- transmettre ;
- devenir client, mentor, rival ou contact ;
- perdre de l’influence ;
- gagner en influence ;
- cesser de travailler tout en restant dans la mémoire de Marion.

Les relations ne sont jamais remises à zéro après plusieurs années.

---

# 7 — GÉNÉRATIONS DE CLIENTÈLE

Exemples :
- première robe de cérémonie → robe de mariage → tenue de mère → fille devenue cliente ;
- musicienne débutante → artiste confirmée → directrice de programmation ;
- curiste occasionnelle → habituée → recommandation à son entourage ;
- jeune designer → concurrent → partenaire → mentor d’une génération plus jeune.

---

# 8 — MONDE CHANGEANT ET RARETÉ

Certaines opportunités :
- reviennent chaque année ;
- reviennent irrégulièrement ;
- sont uniques ;
- deviennent plus rares ;
- disparaissent définitivement ;
- deviennent accessibles seulement après une relation ou un niveau de carrière.

Le joueur ne doit jamais pouvoir tout voir en une partie.

---

# 9 — MÉMOIRE DES LIEUX

Un lieu peut stocker :
- première visite ;
- création liée ;
- rencontre importante ;
- photo ;
- échec ;
- succès ;
- secret découvert ;
- ancienne adresse ;
- transformation du quartier ;
- dernière date de visite.

À la revisite, le jeu compare passé et présent.

---

# 10 — PRINCIPE FINAL

Le monde change sans attendre la joueuse. Mais aucun changement procédural ne doit contredire un lieu réel connu : lorsqu’une modification concerne une institution réelle, utiliser soit une donnée réelle revalidée, soit un événement fictif qui n’altère pas mensongèrement le statut réel de l’institution.
