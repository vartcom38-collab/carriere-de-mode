# HAUTE COUTURE LIVE — ALLIER (03) — SYNTHÈSE FINALE PRÊTE INTÉGRATION V1

Référentiel : checklist territoriale officielle + gabarit éditorial Nîmes ville test.

Statut : **PRÊT POUR INTÉGRATION TERRITORIALE V1**.

---

# 1 — IDENTITÉ DU DÉPARTEMENT

L’Allier doit exister en jeu comme un territoire de contrastes :
- Bourbonnais historique ;
- costume et scène à Moulins ;
- thermalisme, architecture et prestige à Vichy ;
- culture populaire, musique et mémoire industrielle à Montluçon ;
- petites villes thermales et patrimoniales ;
- villages de caractère ;
- artisanat et seconde main ;
- paysages ruraux et forestiers ;
- réseau de châteaux et d’anciens centres bourbonnais.

La structure n’est pas une hiérarchie de valeur : chaque pôle possède une raison spécifique d’y aller.

---

# 2 — PÔLES PRIORITAIRES

## Moulins
Rôle principal : costume, scène, design textile, patrimoine, archives.

Ancrages :
- CNCS ;
- Maison des Métiers d’Art et du Design ;
- Théâtre ;
- Espace Patrimoine ;
- château / héritage ducal ;
- hôtels particuliers ;
- archives municipales ;
- événements nocturnes.

Gameplay : apprentissage justifié, recherche costume, briefs de scène, patrimoine, shooting, Book, réseau culturel.

## Vichy
Rôle principal : thermalisme, élégance, réception, architecture, internationalité modérée.

Ancrages :
- quartier thermal ;
- Opéra / Palais des Congrès ;
- Hall des Sources ;
- galeries ;
- villas ;
- hippodrome ;
- archives municipales ;
- événements saisonniers.

Gameplay : clientèle cérémonie/prestige, congrès, gala, cure, shooting, événements historiques, seconde main.

## Montluçon
Rôle principal : musique, populaire, industriel, médiéval.

Ancrages :
- MuPop ;
- cité médiévale ;
- château ;
- canal ;
- rotonde / mémoire ferroviaire ;
- événements culturels ;
- parcours lumière.

Gameplay : scène, musique, costume, jeune clientèle, transformations, seconde main, patrimoine industriel.

---

# 3 — PÔLES SECONDAIRES

## Bourbon-l’Archambault
Thermalisme intime + héritage bourbonnais + clientèle fidèle.

## Néris-les-Bains
Séjour thermal + confort + petite réception + revisites saisonnières.

## Charroux
Artisanat + patrimoine + shooting + petites adresses/secrets.

## Souvigny
Recherche historique + patrimoine religieux/clunisien + cérémonial traité sans folklorisation automatique.

## Lapalisse
Château + événement + halte de passage + clientèle cérémonie et tourisme.

---

# 4 — MATIÈRES / SAVOIR-FAIRE / ATELIER

Sorties possibles :
- TECHNIQUE_LEARNED ;
- TECHNIQUE_OBSERVED ;
- MATERIAL_KNOWLEDGE ;
- DESIGN_REFERENCE ;
- PALETTE_REFERENCE ;
- MOTIF_REFERENCE ;
- CRAFT_CONTACT ;
- COLLAB_CAPABILITY ;
- BOOK_RESEARCH.

Moulins fournit le plus fort axe technique réel via costume, tissage/design textile et métiers d’art.

La règle reste : observation ≠ maîtrise ; inspiration ≠ savoir-faire ; collaboration spécialisée si nécessaire.

---

# 5 — PERSONNAGES / CLIENTÈLE / MISSIONS

Le département possède :
- personnages persistants par grands pôles ;
- PNJ temporaires ;
- clientèle saisonnière ;
- clientèle locale et de passage ;
- 48 briefs transversaux déjà structurés ;
- rumeurs ;
- secrets ;
- mémoire relationnelle ;
- progression début / développement / confirmée / avancée.

Les interactions complexes utilisent des personnages FICTION GAMEPLAY, même lorsqu’elles s’ancrent dans un lieu réel.

---

# 6 — SAISONNALITÉ / CALENDRIER

Le département dispose d’un calendrier JANVIER → DÉCEMBRE consolidé avec :
- thermalisme ;
- culture ;
- patrimoine ;
- musique ;
- seconde main ;
- brocantes ;
- Puces Couturières ;
- événements estivaux ;
- rentrée culturelle ;
- fêtes patrimoniales ;
- événements nocturnes ;
- variations de clientèle.

Toute date réelle doit être revalidée pour l’année effectivement jouée.

---

# 7 — SECONDE MAIN / BROCANTE

La seconde main fonctionne comme contenu variable :
- brocantes ;
- vide-greniers ;
- braderies ;
- Puces Couturières ;
- lots ponctuels ;
- successions ;
- recommandations ;
- stocks changeants.

Conséquences : Atelier, Book, rumeurs, secrets, téléphone, agenda, missions.

---

# 8 — BOOK / PHOTO / SHOOTINGS

Directions visuelles principales :
- Moulins : costume, architecture, cours cachées, patrimoine ;
- Vichy : galeries, villas, thermalisme, parcs, hippodrome ;
- Montluçon : médiéval, industriel, musique, canal ;
- Charroux/Souvigny/Lapalisse : pierre, patrimoine, campagne, cérémonial ;
- Bourbon/Néris : thermalisme plus intime.

Le Book enregistre recherche, création, shooting, rencontre, événement ou évolution marquante, pas chaque visite.

---

# 9 — TRANSPORT / RÉSEAU

Le joueur peut circuler entre les pôles sans changement automatique de résidence.

Logique :
Moulins ↔ Vichy ↔ Montluçon ↔ pôles secondaires ↔ départements voisins.

Les déplacements peuvent créer :
- nouvelles clientes ;
- collaborations ;
- événements ;
- fournisseurs ;
- rencontres ;
- opportunités de Book.

---

# 10 — MONDE CHANGEANT 20–30 ANS

Le moteur de long terme prévoit :
- retraites ;
- transmissions ;
- ouvertures/fermetures ;
- changements de programmation ;
- nouvelles expositions ;
- nouveaux artisans ;
- anciens concurrents devenus décideurs ;
- clientes intergénérationnelles ;
- évolution des quartiers ;
- événements qui apparaissent ou disparaissent.

Une revisite doit pouvoir produire un état du monde différent.

---

# 11 — RÈGLES DE RARETÉ ET CONSÉQUENCE

Chaque élément majeur doit préciser :
- fréquence ;
- condition d’accès ;
- saison ;
- relation/reputation éventuelle ;
- conséquences dans au moins deux systèmes.

Pas de récompense automatique à chaque visite.

---

# 12 — MANQUES NON BLOQUANTS

Enrichissements possibles ultérieurement :
- merceries/fournisseurs textiles supplémentaires ;
- davantage de studios photo réels ;
- sélection plus fine de lieux sociaux ;
- banque plus large de figures locales sourcées ;
- petites communes supplémentaires si elles apportent une vraie singularité.

Aucun de ces points n’empêche l’intégration V1.
