# 2 — GAMEPLAY SECONDE MAIN

Chaque événement de seconde main peut produire :
- vêtement à transformer ;
- lot de boutons ;
- dentelle ou ruban ;
- patron ancien ;
- tissu incomplet ;
- accessoire ;
- livre/revue ;
- photographie ;
- boîte de couture ;
- élément sans valeur immédiate mais utile plus tard.

Rareté :
- commun : vêtements courants, boutons, mercerie basique ;
- peu commun : tissu ancien en bon état, patrons datés, accessoires ;
- rare : pièce ancienne documentée, lot homogène, textile de scène ancien ;
- exceptionnel : objet nécessitant authentification ou recherche, jamais donné gratuitement comme récompense automatique.

# 4 — SAISONNALITÉ

Janvier-février : peu de grands événements extérieurs, contenus intérieurs et dépôts.
Mars-avril : reprise des brocantes, vide-dressings, nettoyages de printemps.
Mai-juin : forte activité, villages, fêtes, marchés.
Juillet-août : tourisme, marchés estivaux, braderies.
Septembre : mois fort 2026 avec Puces Couturières Vichy, braderie Moulins, brocantes Montluçon/Néris.
Octobre : brocantes d’automne, derniers événements extérieurs.
Novembre-décembre : marchés de fêtes, objets/cadeaux, seconde main intérieure.

---

# 6 — SECRETS / RUMEURS

Exemples :
- un lot de galons réapparaît chaque année chez le même vendeur ;
- une boîte de patrons vient d’un ancien atelier ;
- une pièce achetée à Montluçon révèle une étiquette oubliée ;
- une couturière de Vichy connaît l’histoire d’un vêtement de villégiature ;
- une succession à Moulins contient de vieux accessoires de théâtre ;
- une braderie de septembre permet de retrouver un commerce aperçu des années auparavant.

Chaque secret doit avoir : condition, rareté, saison, source et conséquence.

---

# 7 — LIENS SYSTÈMES

Atelier : matière, démontage, transformation, réparation.
Book : trace, provenance, photo avant/après.
Relations : recommandations et confiance.
Téléphone : alerte lot / vendeur / événement.
Agenda : dates réelles et événements procéduraux.
Réputation : certaines personnes gardent de bonnes pièces pour Marion.
Carrière longue : boutiques ferment, vendeurs vieillissent, héritages apparaissent, habitudes changent.
