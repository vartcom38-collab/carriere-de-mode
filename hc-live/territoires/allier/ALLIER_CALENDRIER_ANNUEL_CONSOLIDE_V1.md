# HAUTE COUTURE LIVE — ALLIER (03) — CALENDRIER ANNUEL CONSOLIDÉ — V1

Référentiel : checklist territoriale officielle + format Nîmes.

Règle : les dates réelles exactes doivent être revalidées chaque année. Le moteur utilise une couche de saisons + événements réels datés + événements procéduraux fictifs.

# RYTHMES PAR PÔLE

## Moulins
Toute l’année : costume, patrimoine, recherche.
Pic : programmation culturelle et métiers d’art selon expositions temporaires.

## Vichy
Printemps-été : thermalisme, patrimoine, visiteurs, cérémonie, hippodrome, événements.
Automne-hiver : opéra, architecture, congrès, clientèle fidèle.

## Montluçon
Toute l’année : vie locale, musique, culture.
Été-automne : événements, brocantes, patrimoine, scène.

## Bourbon / Néris
Saisons de cure, tourisme, petites cérémonies.

## Charroux / Souvigny / Lapalisse
Printemps-automne : tourisme, patrimoine, marchés, photographie.
Hiver : vie plus locale, relations persistantes, événements ponctuels.

# ÉVÉNEMENTS PROCÉDURAUX FICTION GAMEPLAY

Chaque année peut aussi générer :
- résidence d’artiste ;
- exposition textile temporaire ;
- appel à créateurs ;
- mariage important ;
- spectacle en tournée ;
- vente de succession ;
- atelier temporaire ;
- pop-up créateur ;
- défilé associatif ;
- congrès ;
- shooting éditorial ;
- fermeture exceptionnelle ;
- travaux modifiant l’accès à un lieu.

Ces événements sont explicitement fictifs même lorsqu’ils utilisent une ville réelle.

# IMPACTS SYSTÈMES

Agenda : programmation et anticipation.
Téléphone : invitation / urgence / rappel.
Carte : lieux activés selon saison.
Relations : certains personnages présents seulement certains mois.
Atelier : matières et techniques disponibles selon événements.
Book : traces saisonnières différentes.
Carrière : opportunités adaptées au niveau.
