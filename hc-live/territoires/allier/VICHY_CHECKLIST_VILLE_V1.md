# HAUTE COUTURE LIVE — VICHY — CHECKLIST VILLE V1

Référentiel : checklist territoriale officielle + gabarit éditorial Nîmes ville test.

Statut : PREMIÈRE PASSE AVANCÉE — À DENSIFIER.

---

# 1 — IDENTITÉ DE VILLE

Vichy doit être traitée comme une ville thermale, patrimoniale, élégante, événementielle et saisonnière. Son identité ne se résume pas au luxe : elle combine thermalisme, villégiature, architecture Second Empire / Belle Époque / Art nouveau / Art déco, opéra, hippisme, parcs, hôtels, congrès, clientèle de passage et mémoire historique sensible.

Gameplay : ville de rendez-vous, d’image, de réception, de tenue de cérémonie, de spectacle, de clientèle mobile et de recherches visuelles. Elle doit fonctionner très différemment selon haute saison, événements, cure, hippisme, congrès et calendrier culturel.

# 8 — 20 BRIEFS INITIAUX

Début :
1. retouche d’une robe pour dîner d’hôtel ;
2. transformation d’une veste ancienne ;
3. tenue confortable pour cure ;
4. réparation urgente avant spectacle ;
5. accessoirisation d’une tenue de mariage ;

Développement :
6. petite capsule pour une cliente en séjour long ;
7. robe inspirée d’une palette ivoire/or de l’Opéra sans copie historique ;
8. tenue pour événement hippique ;
9. deux looks jour/soir pour congressiste ;
10. upcycling d’une pièce trouvée lors d’une brocante ;

Confirmée :
11. tenue de scène ;
12. vestiaire capsule pour hôtellerie / réception ;
13. série de silhouettes pour shooting patrimonial ;
14. mariage avec plusieurs membres d’une même famille ;
15. collaboration événementielle avec scénographie ;

Avancée :
16. projet capsule autour du thermalisme contemporain ;
17. création pour gala à l’Opéra ;
18. projet transfrontalier / international lié aux villes d’eaux ;
19. exposition personnelle dans un lieu culturel fictif partenaire ;
20. commande d’image complète pour personnalité de passage fictive.

# 9 — RUMEURS / SECRETS

Rumeurs FICTION GAMEPLAY :
- une ancienne cliente conserve une malle de vêtements jamais montrée ;
- une habilleuse sait où trouver un excellent retoucheur ;
- un hôtel rénove une suite et prépare un lancement privé ;
- un lot textile va apparaître dans une vente locale ;
- une compagnie revient chaque année avec le même problème de costumes.

Secrets :
- archive graphique non exposée accessible après relation avec une médiatrice ;
- adresse de brocante connue seulement par recommandation ;
- ancien carnet de commandes d’une couturière fictive ;
- salon privé d’hôtel utilisé ponctuellement pour essayages ;
- cliente historique qui ne contacte Marion qu’après plusieurs années de réputation locale.

# 10 — ATELIER / BOOK

Sorties possibles :

- PALETTE_REFERENCE : ivoire, or, verts de parc, bleu d’eau, tons pierre ;
- MOTIF_REFERENCE : ferronneries, vitraux, végétaux stylisés ;
- MATERIAL_KNOWLEDGE : tissus de cérémonie, confort, doublures légères, tissus de voyage ;
- TECHNIQUE_OBSERVED : habillage spectacle, entretien costume, travail vitrail comme source visuelle ;
- COLLAB_CAPABILITY : spectacle, réception, photographie, événementiel ;
- BOOK_RESEARCH : séries architecturales, lumière nocturne, patrimoine thermal.

Aucune visite patrimoniale ne débloque automatiquement une technique couture.
