# HAUTE COUTURE LIVE — MONTLUÇON — CHECKLIST VILLE V1

Référentiel : checklist territoriale officielle + gabarit éditorial Nîmes ville test.

Statut : PREMIÈRE PASSE AVANCÉE — À DENSIFIER.

---

# 1 — IDENTITÉ DE VILLE

Montluçon doit être traitée comme un pôle de contraste : cité médiévale, patrimoine industriel, culture populaire, musique, mémoire ferroviaire, canal de Berry, grands équipements culturels et vie événementielle. Elle ne doit pas être jouée comme une simple ville patrimoniale : son intérêt vient du mélange ancien / industriel / populaire / musical / contemporain.

---

# 2 — ZONES / PÔLES

À structurer :
- cité médiévale ;

- Athanor ;
- canal de Berry ;
- secteur gare / rotonde ferroviaire ;
- zones industrielles / mémoire ouvrière ;
- liaisons vers Domérat et environs.

---

# 3 — CULTURE / PATRIMOINE RÉELS

Pôles prioritaires :
- MuPop ;
- château des ducs de Bourbon ;
- cité médiévale ;
- patrimoine ferroviaire / rotonde ;
- église Saint-Paul et Maison communale ;
- canal de Berry ;
- patrimoine industriel et ouvrier ;
- Montluçon en lumières comme usage nocturne temporaire.

Le MuPop doit surtout nourrir : costume de scène, culture musicale, image publique, accessoires, époque, sous-cultures, performance, affiche et photographie.

# 9 — RUMEURS / SECRETS

- réserve d’affiches ou photos accessibles après relation ;
- ancien costume de groupe retrouvé dans un fonds fictif ;
- brocanteur qui met de côté les meilleures pièces ;
- local de répétition où circulent des commandes ;
- ancien atelier familial disparu ;
- contact ferroviaire permettant un shooting exceptionnel ;
- petite salle qui cherche une identité vestimentaire ;
- artiste de passage revenant plusieurs années plus tard.

---

# 10 — ATELIER / BOOK

- DESIGN_REFERENCE : culture musicale, médiéval, industrie, canal, ferroviaire ;
- MATERIAL_KNOWLEDGE : denim, cuir apparent uniquement comme matériau documenté si source réelle, tissus robustes, seconde main ;
- TECHNIQUE_OBSERVED : entretien costume, transformation, réparation, habillage de scène ;
- COLLAB_CAPABILITY : musique / scène / photographie ;
- BOOK_RESEARCH : portraits, série nuit, patrimoine industriel, culture populaire.
