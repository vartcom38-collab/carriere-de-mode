# 4 — SECRETS

## Secrets de savoir-faire
- accès à une démonstration plus avancée après plusieurs rencontres ;
- compréhension d’un détail technique grâce à un contact transmis par une dentellière ;
- fonds non exposé accessible dans un cadre documentaire.

## Secrets de matière
- petit lot de fil ancien ;
- dentelle inachevée utilisable uniquement après expertise ;
- pièce textile abîmée mais historiquement intéressante ;
- stock dormant provenant d’un ancien commerce FICTION GAMEPLAY.

## Secrets humains
- ancienne rivalité entre deux ateliers fictifs ;
- apprentie qui envisage de reprendre une activité ;
- cliente liée à une ancienne commande de Marion ;
- bénévole de festival connaissant plusieurs générations d’artistes.

## Secrets carrière longue
- lieu découvert au début du jeu qui ferme puis réapparaît sous une autre forme ;
- ancien personnage secondaire devenu responsable d’institution ;
- ancienne cliente devenue mécène ;
- jeune dentellière rencontrée à 20 ans devenue référence à 40 ans.

# 5 — MÉMOIRE ANTI-REDONDANCE

Chaque brief doit enregistrer :
- famille de mission ;
- territoire ;
- événement lié ;
- type de cliente ;
- matière ;
- technique ;
- lieu ;
- enjeu narratif ;
- niveau de carrière ;
- personnes impliquées.

Une nouvelle proposition trop proche d’une ancienne doit modifier au moins deux dimensions importantes parmi : cliente / matériau / lieu / contrainte / relation / enjeu / statut de Marion / forme finale.
