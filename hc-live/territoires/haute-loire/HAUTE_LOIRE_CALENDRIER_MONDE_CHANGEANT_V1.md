# 3 — ÉVOLUTION DES ÉVÉNEMENTS 2027→2056

Chaque événement conserve une identité mais pas un scénario fixe.

Variables annuelles :
- thème ;
- artistes ;
- lieux ;
- taille ;
- budget ;
- météo ;
- direction ;
- partenaires ;
- public ;
- présence ou non d’une opportunité mode ;
- visibilité de Marion ;
- personnages invités ;
- concurrence.

Un événement peut :
- revenir ;
- faire une pause ;
- déménager partiellement ;
- créer une édition anniversaire ;
- réduire sa programmation ;
- changer de direction ;
- ouvrir une résidence ;
- disparaître ;
- être remplacé ;
- faire émerger un événement concurrent.

# 5 — ANTI-REDONDANCE

Une édition d’un événement ne doit pas proposer la même boucle si Marion a déjà vécu une expérience équivalente.

Exemple La Chaise-Dieu :
- année 1 : observation / rencontre ;
- année 3 : retouche urgente pour une musicienne ;
- année 6 : costume de scène ;
- année 10 : collaboration avec production ;
- année 15 : invitation comme créatrice confirmée ;
- année 22 : jury / mentorat ;
- année 27 : retour d’une artiste rencontrée vingt ans auparavant.

L’absence de mission est une issue valide : certains événements ne produisent qu’ambiance, population temporaire, relation, inspiration ou souvenir.
