# HAUTE COUTURE LIVE — LE PUY-EN-VELAY — CHECKLIST VILLE V1

Format Nîmes adapté.

## 1. IDENTITÉ
Le Puy = dentelle d’excellence + patrimoine + tourisme + transmission + réseau culturel. Ce n’est pas seulement une ville-musée : le savoir-faire dentellier y est encore vivant, enseigné et renouvelé.

## 2. LIEUX / RECHERCHE
- Atelier Conservatoire National de la Dentelle ;
- Centre d’Enseignement de la Dentelle aux Fuseaux ;
- Musée Crozatier ;
- archives municipales ;
- centre historique ;
- patrimoine religieux/civil ;
- commerces et lieux sociaux à approfondir.

## 3. DENTELLE — GAMEPLAY
La dentelle du Puy utilise un carreau/tambour, des fuseaux, des épingles et un carton-modèle. Les fibres peuvent inclure lin, coton, soie, laine et fils métalliques.

Le jeu distingue :
- visite = TECHNIQUE_OBSERVED ;
- initiation encadrée = premier niveau TECHNIQUE_LEARNED ;
- stage/formation = progression technique ;
- observation d’œuvre = MOTIF_REFERENCE / DESIGN_REFERENCE ;
- rencontre professionnelle = CRAFT_CONTACT ;
- projet commun = COLLAB_CAPABILITY.

Aucune visite simple ne transforme Marion en dentellière experte.

## 4. 2026 COMME BASE RÉELLE
En 2026, l’Atelier Conservatoire célèbre 50 ans d’existence dans le cadre d’expositions nationales ; des visites régulières permettent de rencontrer les dentellières. Le Centre d’Enseignement présente notamment l’exposition « Fragility » en 2026.

Ces contenus servent de base documentaire : les années futures sont simulées sans prétendre connaître les programmes réels.

## 8. 20 BRIEFS
Début : pose d’un détail textile ; transformation d’une pièce familiale ; tenue invitée ; petit accessoire ; stylisme photo.
Développement : collaboration avec apprentie dentellière ; motif contemporain ; petite série ; pièce cérémonie ; éditorial patrimoine.
Confirmée : robe intégrant panneau dentelle collaboratif ; commande institutionnelle ; costume de scène ; capsule contemporaine ; exposition.
Avancée : direction créative avec artisanes ; transmission/mentorat ; rétrospective ; commande prestige ; projet interterritorial avec Moulins/Brioude/Alençon selon connexions de carrière.

## 9. SECRETS
cartons anciens, motif abandonné, recommandation d’une dentellière, réserve non visible, fonds photo, pièce inachevée, commande historique documentée, contact vers Retournac/Brioude/Blesle.

## 10. BOOK
motifs, cartons, outils, gestes, œuvres contemporaines, patrimoine, collaborations, étapes d’apprentissage.

## 11. REVISITES
Le lieu change avec : expositions, formatrices, niveau de Marion, accès aux réserves, stages suivis, collaborations passées, nouvelles générations d’élèves.

## 12. ANTI-REDONDANCE
Une nouvelle visite ne doit pas redonner le même motif ou le même « apprentissage ». Progression : observer → essayer → pratiquer → collaborer → créer → transmettre.
