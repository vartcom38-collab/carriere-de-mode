# HAUTE COUTURE LIVE — AIN (01) — CALENDRIER ANNUEL CONSOLIDÉ V2

Statut : chantier actif — branche `territoires-france`.

Objectif : fournir un calendrier annuel départemental exploitable par le moteur de territoire. Les dates exactes des événements réels doivent être revalidées chaque année. Les périodes ci-dessous servent de structure saisonnière et de logique gameplay.

---

# JANVIER

Ambiance : hiver, montagne, activité culturelle intérieure, retouches et commandes de nouvelle année.

Territoires forts :
- Pays de Gex / Monts Jura ;
- Haut-Bugey ;
- Bourg-en-Bresse ;
- Belley / Bugey Sud.

Gameplay :
- vêtements chauds / déplacement ;
- réparation de manteaux ;
- accessoires hiver ;
- recherches en musée / archives ;
- shootings neige si conditions ;
- préparation de projets printemps.

# COUCHES TRANSVERSALES

Le moteur doit agréger :
1. événements réels revalidés ;
2. événements FICTION GAMEPLAY compatibles ;
3. saison touristique ;
4. météo / paysage ;
5. disponibilité des personnages ;
6. rythme des matières / fournisseurs ;
7. mariage / spectacle / festivals ;
8. niveau de carrière de Marion ;
9. territoire de présence réel ;
10. mémoire des années précédentes.

Un événement ne se transforme jamais automatiquement en mission. Il crée un contexte dans lequel une opportunité peut apparaître.
