# HAUTE COUTURE LIVE — AIN (01) — DENSIFICATION AU FORMAT NÎMES VILLE TEST — V2

Référentiel éditorial : DOCUMENT MAÎTRE GAMEPLAY V2 — NÎMES VILLE TEST.

Objectif : appliquer à l’Ain la même logique de profondeur que Nîmes sans copier son identité culturelle.

Règle : réel documenté ≠ fiction gameplay. Les lieux et événements réels servent de contexte ; les contrats, dialogues et personnes interactives sont fictifs sauf mention contraire.

# 6 — RÈGLES NÎMES APPLIQUÉES À TOUT L’AIN

Chaque pôle doit désormais avoir :
- au moins 1 identité claire ;
- lieux réels vérifiés ;
- lieux gameplay fictifs signalés comme tels ;
- population persistante ;
- population temporaire ;
- briefs de plusieurs niveaux ;
- secrets/rumeurs non visibles au départ ;
- sorties Atelier/Book ;
- téléphone/agenda possibles ;
- revisites ;
- événements saisonniers ;
- changement du monde ;
- connexions avec les autres territoires.

Aucun pôle n’est validé uniquement parce qu’il possède des pins sur une carte.
