# HAUTE COUTURE LIVE — AIN (01) — CONNEXIONS, VOYAGES, RÉSEAUX

Statut : chantier actif sur `territoires-france`.

Cette fiche applique les sections CONNEXIONS ENTRE VILLES / DÉPARTEMENTS / RESTE DE LA FRANCE de la checklist territoriale officielle.

Règle : voyager n’implique jamais déménager. La résidence de Marion reste indépendante de ses territoires de présence, de clientèle et de travail.

---

# 1 — PRINCIPE

Les communes de l’Ain ne doivent jamais fonctionner comme des îles.

Une rencontre, une matière, un événement ou un client dans une commune peut ouvrir :
- une adresse dans une autre commune ;
- un artisan ailleurs dans le département ;
- un événement ;
- un shooting ;
- une mission ;
- un fournisseur ;
- une nouvelle relation ;
- une raison de voyager.

Le réseau doit suivre les vrais bassins économiques, culturels, patrimoniaux et de mobilité.

---

# 2 — AXE BOURG-EN-BRESSE ↔ BRESSE / REVERMONT

Raisons de voyager :
- administration et culture ;
- cérémonies ;
- commerce ;
- patrimoine ;
- gastronomie / événementiel ;
- villages artisanaux ;
- photographie ;
- marchés ;
- Glorieuses de Bresse.

Connexions utiles :
- Bourg ↔ Vonnas ;
- Bourg ↔ Meillonnas ;
- Bourg ↔ Treffort / Revermont ;
- Bourg ↔ Saint-Étienne-du-Bois ;
- Bourg ↔ Pont-de-Vaux / Bresse nord.

Gameplay possible :
- une cliente rencontrée à Bourg recommande un domaine ou un artisan rural ;
- une recherche au musée mène à une commune du Revermont ;
- un photographe de Bourg propose un shooting dans un village ou paysage proche ;
- un événement de décembre attire des clientes de plusieurs communes.

# 4 — AXE BUGEY ↔ Jujurieux ↔ Cerdon ↔ Ambérieu

Cet axe doit être un des grands parcours internes de l’Ain.

Raisons :
- soie ;
- archives textiles ;
- cuivre / métal ;
- patrimoine industriel ;
- vallées ;
- mémoire ouvrière ;
- transports par Ambérieu.

Connexions possibles :
- Jujurieux ↔ Lyon par histoire textile ;
- Jujurieux ↔ Cerdon par patrimoine industriel ;
- Ambérieu ↔ Jujurieux / Cerdon comme porte d’entrée ferroviaire et de réseau ;
- Bugey ↔ Belley / sud du département.

Gameplay :
- recherche textile à Jujurieux → artisan métal à Cerdon ;
- archives → nouvelle source matière ;
- photographe patrimoine → autre vallée ;
- invitation à une visite ou rencontre spécialisée ;
- projet croisant textile + métal à carrière avancée.

- plasturgie ;

- prototypes ;

# 6 — AXE OYONNAX / HAUT-BUGEY ↔ LYON

Connexion naturelle pour :
- design ;
- sous-traitance ;
- fabrication ;
- clients ;
- écoles ;
- événements professionnels ;
- fournisseurs.

Le jeu ne doit pas présenter Lyon comme « niveau supérieur » : c’est simplement un autre bassin avec davantage de certaines opportunités.

---

# 7 — AXE PAYS DE GEX ↔ GENÈVE

Connexion structurante.

Raisons :
- travail transfrontalier ;
- clientèle internationale ;
- événements ;
- aéroport ;
- culture ;
- salons ;
- hôtellerie ;
- mobilité professionnelle.

Gameplay :
- personne rencontrée à Gex travaille à Genève ;
- cliente réside dans l’Ain mais travaille en Suisse ;
- événement genevois provoque une commande ou un voyage ;
- shooting / cérémonie / gala peut se dérouler de l’autre côté de la frontière ;
- retour à domicile dans l’Ain après travail extérieur.

Aucune invitation professionnelle ne doit modifier automatiquement la résidence de Marion.

- retour dans l’Ain après un événement national.

# 14 — CONNEXIONS PAR PERSONNAGES

Chaque personnage persistant peut posséder :
- commune de vie ;
- commune de travail ;
- communes fréquentées ;
- territoires professionnels ;
- territoires familiaux ;
- événements réguliers.

Exemple FICTION GAMEPLAY :
une photographe vit à Bourg, travaille des mariages en Dombes et photographie parfois des créations à Pérouges.

Cela permet de faire circuler les mêmes visages dans plusieurs lieux sans créer une population artificiellement cloisonnée.

---

# 15 — CONNEXIONS PAR MATIÈRES / SAVOIR-FAIRE

Exemples :
- soie de Jujurieux → création à Bourg ;
- prototype d’Oyonnax → shooting à Pérouges ;
- détail métallique inspiré de Cerdon → accessoire produit avec un contact du Haut-Bugey ;
- pierre de Mijoux → bijou ou accessoire de cérémonie ;
- référence de Meillonnas → motif / direction artistique ailleurs dans le département.

La matière ne doit pas être enfermée dans son lieu d’origine après découverte.

---

# 16 — VOYAGE ET TEMPS

Chaque déplacement doit avoir :
- origine ;
- destination ;
- motif ;
- temps de trajet simulé ;
- éventuellement coût ;
- événement / rendez-vous lié ;
- retour ou prolongation choisi par la joueuse.

Pas de téléportation narrative automatique pour les moments importants.

---

# 17 — CARRIÈRE LONGUE

Au fil des années :
- anciens contacts peuvent déménager ;
- nouveaux axes professionnels apparaissent ;
- une cliente locale peut travailler ailleurs ;
- un artisan peut transmettre son activité ;
- un festival peut devenir plus important ;
- Marion peut revenir dans un ancien territoire avec un réseau différent ;
- sa réputation peut circuler dans des territoires où elle ne vit pas.

---

# 18 — MANQUES À RECHERCHER

- temps de trajet et liaisons ferroviaires précises ;
- circuits professionnels réels industrie / artisanat ;
- flux touristiques saisonniers plus détaillés ;
- médias régionaux reliant les bassins ;
- salons et foires professionnels régionaux ;
- connexions précises vers Jura, Savoie, Rhône, Saône-et-Loire et Haute-Savoie ;
- connexions internationales via Genève.

Ces points seront complétés lors du traitement des départements voisins afin de garder une seule architecture cohérente.
