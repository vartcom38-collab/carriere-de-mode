# HAUTE COUTURE LIVE — AIN — VINTAGE / BROCANTES / SECONDE MAIN

Branche : `territoires-france`

Objectif : traiter la catégorie brocantes / friperies / vintage de la checklist officielle sans inventer des adresses permanentes là où le territoire fonctionne surtout par rendez-vous ponctuels.

---

# 1 — PRINCIPES GAMEPLAY

La seconde main dans l'Ain doit combiner :
- friperies permanentes lorsqu'elles sont réellement documentées ;
- vide-greniers ;
- braderies commerçantes ;
- bourses vêtements ;
- marchés saisonniers ;
- ventes associatives ;
- pièces familiales transmises via personnages fictifs ;
- lots textiles / linge ancien découverts par bouche-à-oreille.

Une brocante ne garantit jamais une trouvaille exceptionnelle.

Rareté possible :
- commune : vêtement courant à transformer ;
- inhabituelle : matière ou détail intéressant ;
- rare : vêtement ancien / tissu de qualité / accessoire ;
- très rare : pièce documentée ou provenance intéressante ;
- exceptionnelle : archive / pièce historique, uniquement avec justification forte.

La nature exacte du stock doit rester dynamique : ne pas figer des marques ou pièces non sourcées.

# 9 — MISSIONS FICTION GAMEPLAY

- transformer un manteau acheté en seconde main ;
- restaurer une robe trouvée en vide-grenier ;
- recomposer deux pièces ordinaires en une tenue ;
- adapter un vêtement de ski ancien ;
- identifier si un textile ancien mérite conservation plutôt que découpe ;
- chercher une pièce précise pour un shooting ;
- travailler à budget contraint pour une cliente ;
- valoriser une pièce familiale transmise.

Règle : le jeu doit parfois pousser Marion à NE PAS découper une pièce si elle a une valeur patrimoniale.
