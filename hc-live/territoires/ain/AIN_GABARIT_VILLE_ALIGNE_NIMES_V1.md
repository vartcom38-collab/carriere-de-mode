# HAUTE COUTURE LIVE — AIN — GABARIT VILLE ALIGNÉ SUR NÎMES VILLE TEST

Ce document fixe la mise en forme éditoriale commune des villes et bassins de l'Ain à partir du modèle de production Nîmes ville test.

IMPORTANT : Nîmes sert de gabarit de STRUCTURE, jamais de modèle esthétique ou culturel à recopier.

Chaque ville doit conserver sa propre identité territoriale.

---

# 1 — IDENTITÉ DE LA VILLE / DU PÔLE
- rôle territorial ;
- personnalité dominante ;
- histoire utile ;
- paysages / architecture ;
- saisonnalité ;
- raisons d'y vivre / travailler / revenir.

# 2 — CULTURE / PATRIMOINE RÉELS
Pour chaque lieu important :
- nom réel ;
- fonction réelle ;
- intérêt culturel ;
- intérêt potentiel pour une créatrice ;
- saison / exposition / événement éventuel ;
- revisite possible.

Ne jamais forcer une traduction mode.

# 3 — RECHERCHE / ARCHIVES
- archives ;
- bibliothèques ;
- fonds photographiques ;
- collections textiles ;
- fonds industriels ;
- documents locaux ;
- expositions temporaires.

Sorties possibles : BOOK_RESEARCH, DESIGN_REFERENCE, MATERIAL_KNOWLEDGE, PALETTE_REFERENCE, MOTIF_REFERENCE.

# 4 — MODE / MATIÈRES / SAVOIR-FAIRE
- matières locales ou accessibles ;
- fournisseurs ;
- merceries / tissus ;
- artisans ;
- entreprises utiles ;
- savoir-faire ;
- rareté ;
- niveau de carrière ;
- apprentissage réel vs observation vs collaboration.

# 5 — LIEUX GAMEPLAY FICTIFS
Toujours identifiés FICTION GAMEPLAY.

Familles possibles :
- mercerie ;
- brocante textile ;
- café / lieu social ;
- studio photo ;
- atelier ;
- showroom ;
- hôtel temporaire ;
- lieu discret ;
- adresse recommandée.

Ne jamais leur attribuer une fausse adresse réelle précise.

# 6 — TRANSPORT / VOYAGE
- gare ;
- routes / liaisons utiles ;
- villes connectées ;
- durée / coût lorsque le moteur en a besoin ;
- impact agenda / deadlines ;
- aucune modification automatique de résidence.

# 7 — VIE TEMPORAIRE DE CARTE
Prévoir selon jour / saison / événement :
- rumeur ;
- affiche ;
- inspiration ;
- rencontre ;
- vente ponctuelle ;
- marché ;
- exposition ;
- événement ;
- atelier ouvert ;
- démonstration ;
- casting ;
- invitation ;
- opportunité.

Pas de reroll infini par rechargement.

# 8 — PERSONNAGES PERSISTANTS
Chaque personnage fictif important doit avoir :
- identité ;
- rôle ;
- personnalité ;
- style ;
- goûts ;
- niveau d'exigence ;
- territoire de vie ;
- lieux fréquentés ;
- habitudes ;
- saisonnalité ;
- réseau ;
- affinité ;
- confiance ;
- respect ;
- historique ;
- première rencontre ;
- recommandations ;
- missions faites ensemble ;
- tensions / réussites ;
- évolution sur plusieurs années.

# 9 — PNJ TEMPORAIRES / PASSAGE
- touristes ;
- artistes ;
- festivaliers ;
- journalistes ;
- clients de passage ;
- commerciaux ;
- étudiants ;
- professionnels ;
- voyageurs.

# 10 — RENCONTRES LIBRES
Chaque rencontre peut être :
- banale ;
- importante ;
- unique ;
- répétée ;
- professionnelle ;
- amicale ;
- concurrentielle ;
- cliente ;
- prescripteur ;
- mentor ;
- artisan ;
- journaliste ;
- styliste ;
- inconnu.

Une rencontre ne devient pas automatiquement un contact.

# 11 — CLIENTÈLE
Définir par ville :
- profils ;
- budgets ;
- délais ;
- saisonnalité ;
- événements déclencheurs ;
- besoins vestimentaires ;
- niveau de carrière requis.

# 12 — MISSIONS / BRIEFS
Créer une banque par niveau :
- début ;
- développement ;
- confirmée ;
- avancée.

Chaque brief doit préciser :
- contexte territorial ;
- client / commanditaire fictif ;
- besoin ;
- contrainte ;
- saison ;
- délai ;
- matière / technique éventuelle ;
- conséquences possibles ;
- suites possibles.

# 13 — SECRETS / RUMEURS / RECOMMANDATIONS
Pour chaque secret :
- type ;
- rareté ;
- condition de découverte ;
- personne / lieu déclencheur ;
- durée de validité éventuelle ;
- ce que cela ouvre ;
- possibilité de ne jamais le découvrir.

# 14 — ÉVÉNEMENTS
Pour chaque événement réel :
- période ;
- nature ;
- transformation de la ville ;
- population présente ;
- demandes possibles ;
- opportunités ;
- limites ;
- revisite annuelle.

Pour les événements fictifs : marquage FICTION GAMEPLAY.

# 15 — ATELIER
Classer chaque apport :
- TECHNIQUE_LEARNED ;
- TECHNIQUE_OBSERVED ;
- MATERIAL_KNOWLEDGE ;
- DESIGN_REFERENCE ;
- PALETTE_REFERENCE ;
- MOTIF_REFERENCE ;
- CRAFT_CONTACT ;
- COLLAB_CAPABILITY.

Règle : observation ≠ maîtrise.

# 16 — BOOK
Peuvent devenir traces :
- photos ;
- carnet de recherche ;
- archive ;
- lieu ;
- détail ;
- palette ;
- matière ;
- rencontre ;
- événement ;
- création ;
- exposition ;
- souvenir professionnel.

Tout n'est pas ajouté automatiquement.

# 17 — TÉLÉPHONE / AGENDA

- messages ;
- recommandations ;
- invitations ;
- appels ;
- nouvelles adresses ;
- clientes ;

# 18 — RÉPUTATION / RÉSEAU
Pas de score territorial abstrait obligatoire.

Suivre plutôt :
- qui connaît Marion ;
- dans quel milieu ;
- pour quoi ;
- grâce à qui ;
- avec quelle mémoire ;
- quelles portes sont désormais accessibles.

# 19 — SHOOTINGS
- lieux ;
- saison idéale ;
- lumière ;
- accès ;
- type d'image ;
- contraintes ;
- lien Book / Ateliergram / presse.

# 20 — REVISITES / CARRIÈRE LONGUE
Prévoir :
- première visite ;
- familiarité ;
- relation ;
- accès privé ;
- nouvelles expositions ;
- nouveau stock ;

- transmission ;
- ancienne cliente ;
- retour comme professionnelle confirmée ;
- mentorat ;
- jury ;
- rétrospective.

# 21 — CHANGEMENT DU MONDE
Banque possible :
- ouverture ;
- fermeture ;
- retraite ;
- reprise ;
- changement de direction ;

- ville ;

- région ;

# 23 — RÈGLE DE CLÔTURE
Une ville n'est prête que si :
- les lieux majeurs sont documentés ;
- les fonctions culturelles / pro / sociales existent ;
- les rencontres existent dans et hors lieux ;
- les personnages ont une mémoire ;
- le territoire nourrit Atelier et Book ;
- les événements transforment la ville ;
- les éléments temporaires changent ;
- téléphone / agenda reçoivent des conséquences ;
- les revisites comptent ;
- la ville reste intéressante plusieurs années plus tard.
