# HAUTE COUTURE LIVE — REVERMONT / TRÉVOUX — CHECKLIST PÔLES V1

Statut : pôles spécialisés en cours de remplissage sur `territoires-france`.

# 1 — REVERMONT

## ADN
Piémont jurassien, pierre, villages en pente, argile, faïence, poterie, ancien vignoble, caves, artisanat et transmission.

## Réel documenté
- Musée du Revermont à Cuisiat, musée de France, consacré aux caractéristiques culturelles et sociales du Revermont ;
- exposition permanente sur la manufacture de Meillonnas et les techniques de faïence ;
- Meillonnas : argiles exploitées depuis des siècles, activité potière attestée au XVe siècle, production de terre vernissée, faïence, tuiles et carreaux ;
- identité architecturale : pierre, caves, villages de pente, traces d’ancien vignoble.

## Communes prioritaires
- Meillonnas : faïence, argile, motifs ;
- Cuisiat / Val-Revermont : musée, mémoire sociale ;
- Treffort : village, pierre, paysage, ancien vignoble ;
- Ceyzériat / Journans : connexions Bourg–Revermont, nature et habitat.

## Atelier
- argile comme source indirecte ;
- surfaces vernissées ;
- palettes terre, crème, vert, bleu, brun ;
- bordures et fleurs de faïence ;
- structures de pavage ;
- petites séries artisanales ;
- lin / fibres rustiques à traiter comme ambiance locale seulement si source réelle confirmée.

## Personnages — FICTION GAMEPLAY
- potière / céramiste ;
- médiatrice musée ;
- photographe de village ;
- restauratrice d’objets ;
- habitante âgée gardant albums de mariage ;
- jeune artisan ;
- commerçante locale ;
- cliente de cérémonie rurale ;
- organisatrice d’atelier ou marché.

## Missions
Début : palette / carnet, petite retouche, shooting village, accessoire inspiré d’une bordure sans copie.
Développement : collaboration objet / accessoire, série photo artisanale, cérémonie locale, upcycling avec matière trouvée.
Confirmée : capsule artisanat contemporain, scénographie textile + céramique fictive, shooting éditorial dans le Revermont.
Avancée : transmission, résidence fictive, collaboration avec musée ou réseau d’artisans clairement fictionnalisée.

## Secrets
- ancien album de mariage ;
- atelier discret ;
- lot de carreaux / dessins anciens ;
- potière connue seulement localement ;
- cave utilisée pour exposition temporaire ;
- vente de fonds d’atelier.

## Revisites
Le Revermont doit se révéler lentement : marchés saisonniers, ateliers ouverts, départs à la retraite, transmission, changements de village et nouvelles expositions.

# 2 — TRÉVOUX

## ADN
Ancienne capitale de la principauté de Dombes, Saône, patrimoine, orfèvrerie, fil d’or et d’argent, imprimerie, filière en diamant, artisans d’art contemporains, galeries et ateliers.

## Réel documenté
- château et donjon ;
- Palais du Parlement ;
- Musée des Trésors de Trévoux ;
- apothicairerie ;
- fonds patrimonial de la médiathèque La Passerelle ;
- tradition du travail des métaux précieux et invention / diffusion de la filière en diamant ;
- fils d’or et d’argent historiquement utilisés notamment dans les soieries lyonnaises ;
- Rue[s] des Arts avec ateliers et galeries contemporaines ;
- bords de Saône / Voie Bleue.

## Potentiel Atelier / Book
- fil métallique ;
- ornement ;
- broderie métallique comme piste de recherche, pas technique locale automatiquement maîtrisée ;
- bijou ;
- filière / outil / geste ;
- palettes or, argent, pierre, bleu Saône ;
- typographie, imprimerie, dictionnaire et planches anciennes comme sources graphiques ;
- architectures du Parlement et du château.

## Personnages — FICTION GAMEPLAY
- bijoutier·ère ;
- artisan métal ;
- galeriste ;
- médiatrice patrimoine ;
- bibliothécaire du fonds ancien ;
- artiste résident·e ;
- photographe ;
- cliente lyonnaise de passage ;
- organisatrice d’exposition.

## Missions
Début : recherche motif / typographie, retouche de cérémonie, shooting patrimoine, petit accessoire.
Développement : pièce avec détail métallique, collaboration artiste, tenue d’exposition, bijoux / accessoires fictifs.
Confirmée : capsule fil / métal / textile, projet galerie, habillage d’une invitée culturelle.
Avancée : résidence, exposition personnelle, conférence / jury, collaboration patrimoniale fictive.

## Saison
Printemps/été : Saône, tourisme, ateliers et rues animées.
Automne : patrimoine, expositions, fonds documentaires.
Hiver : travail intérieur, bijoux, fêtes, recherches d’archives.

## Secrets
- planches anciennes du fonds patrimonial ;
- atelier d’art accessible par recommandation ;
- ancien outil de filière ;
- bijou familial ;
- vente d’atelier ;
- invitation à vernissage privé.

# 3 — CONNEXIONS
Revermont ↔ Bourg ; Trévoux ↔ Dombes ↔ Lyon ; les liens historiques entre fil d’or/argent de Trévoux et soieries lyonnaises permettent des circuits interterritoriaux documentés sans faire de Lyon une étape obligatoire.

# 4 — MANQUES
- calendrier annuel détaillé ;
- artisans réels contemporains à vérifier individuellement ;
- cafés/hôtels/lieux sociaux utiles ;
- photographes ;
- brocantes/vintage ;
- transports précis ;
- banque de briefs élargie.
