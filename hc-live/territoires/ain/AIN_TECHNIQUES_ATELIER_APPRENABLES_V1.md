# HAUTE COUTURE LIVE — AIN (01) — TECHNIQUES ATELIER RÉELLEMENT APPRENABLES V1

Statut : chantier actif — branche `territoires-france`.

Objectif : distinguer ce qui peut devenir une véritable compétence Atelier de ce qui doit rester une inspiration, une matière, un savoir culturel ou un contact.

---

# 1 — PRINCIPE

Une visite ne débloque pas automatiquement une technique.

Pour qu’une technique soit réellement apprenable, il faut au minimum :
- un savoir-faire identifiable ;
- une personne / structure capable de le transmettre ;
- un contexte crédible d’apprentissage ;
- du temps de jeu ;
- éventuellement plusieurs séances ;
- parfois une relation ou un niveau de carrière suffisant.

---

# 2 — JUJURIEUX / SOIERIES BONNET

## Peut devenir apprentissage technique

- compréhension du dévidage et de la préparation de la soie ;
- lecture du tissage et des armures comme culture technique ;
- analyse d’un velours façonné ;
- lecture d’échantillon textile ;
- repérage qualité / défaut / densité / tombé.

## Ne devient PAS automatiquement une technique maîtrisée

- tissage industriel complet ;
- conduite historique de métiers complexes ;
- restauration textile patrimoniale ;
- reproduction d’une étoffe historique.

Ces éléments demandent expertise spécialisée et restent surtout recherche / culture / collaboration.

---

# 3 — OYONNAX / ACCESSOIRE / PLASTURGIE / LUNETTERIE

## Apprenables via atelier / collaboration encadrée

- lecture d’une plaque d’acétate ;
- choix épaisseur / translucidité ;
- dessin d’un petit accessoire rigide ;
- préparation d’un prototype simple ;
- logique de découpe / assemblage d’accessoire ;
- relation forme-visage pour accessoire / lunettes comme culture design.

## Expertise externe

- moulage industriel ;
- usinage complexe ;
- fabrication réglementée de lunettes ;
- production série.

Le jeu doit alors utiliser une collaboration avec un professionnel plutôt qu’un déblocage magique dans l’Atelier.

---

# 4 — CERDON / DINANDERIE

## Apprenables à niveau initiation

- observation du martelage ;
- dessin de relief ;
- préparation d’un petit élément décoratif ;
- principes de repoussage ;
- compréhension de la rigidité du métal.

## Expertise externe

- pièces complexes ;
- chaudronnerie ;
- finition de haute précision ;
- travail nécessitant outillage spécialisé.

---

# 5 — MIJOUX / LAPIDAIRE

## Apprenables comme culture matière

- identification visuelle de certaines pierres ;
- lecture taille / facette / lumière ;
- choix pierre pour détail ou accessoire ;
- conception d’un serti ou emplacement dans un projet.

## Expertise externe

- taille de pierre fine ou précieuse ;
- sertissage complexe ;
- joaillerie.

---

# 6 — BRESSE / ÉMAUX / DENTELLE / COSTUME

## Apprenables selon transmission réelle

- lecture des structures de dentelle ;
- étude de bordure et placement ;
- observation des systèmes de coiffe et superposition ;
- analyse de bijou émaillé ;
- adaptation raisonnée d’un détail historique.

## À ne pas transformer automatiquement en technique

- reproduction d’un costume traditionnel ;
- fabrication d’émail sans formation ;
- fabrication complète de dentelle experte.

---

# 7 — REVERMONT / MEILLONNAS

## Apprenables comme traduction créative

- construction de palette à partir de céramique ;
- création de bordure / motif inspiré d’un décor ;
- travail de répétition ;
- analyse surface / craquelure / contraste.

Ce n’est pas une technique couture patrimoniale locale : rester dans le champ inspiration / surface / direction artistique.

---

# 8 — SAINT-RAMBERT / SCHAPPE

## Apprenables comme culture textile et réemploi

- différence soie continue / déchets de soie ;
- principe de valorisation d’une fibre secondaire ;
- lecture d’un matériau irrégulier ;
- réflexion qualité / récupération / réemploi.

## Potentiel Atelier

- développement de briefs d’upcycling textile ;
- choix matière ;
- comparaison finitions ;
- narration d’une pièce autour du réemploi.

Ne pas prétendre enseigner industriellement le traitement de la schappe sans structure réelle adaptée.

---

# 9 — DOMBES / NATURE / PÊCHE

Aucune technique couture spécifique n’est débloquée.

Peut nourrir :
- palette ;
- texture ;
- photographie ;
- rythme ;
- vêtement de terrain ;
- observation protection / humidité / mouvement.

---

# 10 — PAYS DE GEX / MONTS JURA

Peut nourrir des compétences de conception :
- stratification du vêtement ;
- protection contre froid / vent ;
- mobilité ;
- choix matière selon usage ;
- détails fonctionnels ;
- ergonomie.

La maîtrise de textile technique industriel reste externe si aucun atelier réel ne l’enseigne directement.

---

# 11 — CATÉGORIES DE SORTIE ATELIER

Chaque découverte doit sortir sous un type précis :

- `TECHNIQUE_LEARNED` : réellement apprise ;
- `TECHNIQUE_OBSERVED` : observée mais non maîtrisée ;
- `MATERIAL_KNOWLEDGE` : connaissance matière ;
- `DESIGN_REFERENCE` : référence de forme / structure ;
- `PALETTE_REFERENCE` ;
- `MOTIF_REFERENCE` ;
- `CRAFT_CONTACT` : professionnel à contacter ;
- `COLLAB_CAPABILITY` : possibilité de faire fabriquer avec un tiers ;
- `BOOK_RESEARCH` : contenu culturel/documentaire seulement.

Cette distinction est obligatoire pour éviter que Marion sache tout faire après une visite de musée.
