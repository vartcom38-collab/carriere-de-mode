# HAUTE COUTURE LIVE — AIN (01) — CALENDRIER, ÉVÉNEMENTS & SAISONNALITÉ

Statut : recherche territoriale — branche `territoires-france`.

Ce document complète `AIN_RECHERCHE_CONTENU_TERRITORIAL_V1.md` et applique les sections calendrier vivant, événements, clientèle saisonnière, musées/expositions, spectacle, tourisme et revisites.

Règle : les événements cités comme réels doivent être vérifiés par année. Le moteur de jeu doit mémoriser leur période habituelle sans supposer que les dates exactes restent identiques chaque année.

---

# 1 — PRINCIPE ANNUEL

L’Ain ne doit jamais conserver la même ambiance douze mois sur douze.

Les grands rythmes retenus :

- hiver : montagne, protection, vie intérieure, archives, ateliers, fêtes et cérémonies de fin d’année ;
- printemps : reprise des sorties, festivals, jardins, patrimoine, marchés, premières fortes demandes de cérémonie ;
- été : festivals, tourisme, patrimoine extérieur, lacs, montagne, mariages, shootings, clientèle de passage ;
- automne : pêche d’étang en Dombes, patrimoine, matières, rentrée professionnelle, musique à Ambronay, retour aux ateliers ;
- décembre : Glorieuses de Bresse, fêtes, cérémonies, cadeaux, réception, forte activité locale spécifique.

# 2 — CALENDRIER JANVIER → DÉCEMBRE

## JANVIER

Rythme dominant : intérieur, montagne, archives, reprise lente après fêtes.

Pistes gameplay :
- Pays de Gex / Monts Jura : vêtements de froid, superpositions, réparations, accessoires et mouvement ;
- Oyonnax : recherche matière / prototypage en intérieur ;
- Jujurieux : archives textiles et recherche documentaire ;
- musées : période propice aux nouveaux accrochages / préparations d’expositions selon programmation réelle ;
- clientèle : retouches, vêtements de travail, hiver, petites commandes moins cérémonielles.

Attention : le Musée du Peigne et de la Plasturgie indique actuellement une fermeture annuelle en janvier pour nouvel accrochage ; le jeu doit vérifier la programmation réelle de l’année concernée avant de reproduire ce détail.

## FÉVRIER

Rythme dominant : montagne, hiver, vie sociale intérieure.

Pistes :
- ski / neige / vêtement technique ;
- shooting hiver ;
- réparation et transformation de pièces chaudes ;
- préparation de collections / projets de printemps ;
- premières recherches mariage et cérémonie.

## MARS

Rythme dominant : transition saisonnière.

Pistes :
- reprise des événements culturels ;
- premiers marchés / jardins ;
- recherches de matières mi-saison ;
- repérages photo ;
- clientèle cérémonie qui commence à augmenter.

## AVRIL

Rythme dominant : patrimoine, extérieur, cérémonies.

Pistes :
- Pérouges et patrimoine ;
- Dombes : retour végétal et oiseaux ;
- Bresse : fermes, jardins, marchés ;
- Book : palettes de printemps ;
- Atelier : matières plus légères ;
- commandes : mariages, communions, baptêmes, événements printaniers.

## MAI

ÉVÉNEMENT RÉEL À SURVEILLER : Nantua Fest (exemple 2026 : 22–24 mai).

Pistes carrière :
- tenues de scène / équipe / artistes seulement à niveau crédible ;
- habillage d’invité ou membre d’organisation ;
- shooting au bord du lac ;
- rencontres musique, photo, événementiel ;
- clientèle de festival et de week-end.

Autres rythmes : mariages, événements extérieurs, retour des fortes fréquentations.

## JUIN

ÉVÉNEMENT RÉEL MAJEUR : Printemps de Pérouges (exemple 2026 : 23–28 juin, au Château de Saint-Maurice-de-Rémens).

Pistes carrière progressives :
- assister ;
- accompagner un contact ;
- habiller une personne du public / invitée ;
- retouche urgente ;
- collaboration avec photographe ;
- travail backstage à carrière plus avancée ;
- prêt de création ;
- tenue d’artiste seulement si réputation et réseau cohérents.

Rythme : forte saison mariage / cérémonie / photo.

## JUILLET

Rythme dominant : festivals, tourisme, lacs, extérieur.

Événements réels repérés pour 2026 à revérifier chaque année :
- Estivales de Brou ;
- Cuivres en Dombes ;
- Oh Bugey Festival ;
- Jazz in Fort l’Écluse (samedis d’été en 2026) ;
- autres festivals estivaux variables.

Gameplay :
- scène / costume / habillage ;
- shootings patrimoniaux ou nature ;
- événements de soirée ;
- clientèle de passage ;
- hôtels / réception ;
- réseau photo et culturel.

## AOÛT

Rythme dominant : tourisme, extérieur, montagne, villages, patrimoine.

Pistes :
- shootings ;
- mariages ;
- fêtes et événements locaux ;
- marchés / brocantes à rechercher commune par commune ;
- clientèle touristique ;
- visites de Dombes / Bugey / Pérouges ;
- découverte d’artisans et petites adresses.

## SEPTEMBRE

ÉVÉNEMENT RÉEL MAJEUR : Festival d’Ambronay (exemple 2026 : 11–27 septembre).

Le festival associe musique, abbaye, ateliers, visites et scènes ; il devient une vraie porte vers le spectacle et l’habillage.

Pistes carrière :
- assister ;
- rencontrer organisateurs / musiciens / photographes ;
- besoin de retouche ;
- tenue de concert ;
- habillage d’artiste ou intervenant à niveau avancé ;
- costume ou pièce de scène si projet spécifique ;
- shooting dans le contexte architectural.

Autre événement : Journées européennes du patrimoine, avec ouvertures et visites spéciales selon programmation.

## OCTOBRE

Rythme dominant : Dombes, pêche d’étang, matières d’automne, retour aux ateliers.

La pêche traditionnelle des étangs constitue une expérience territoriale forte et saisonnière.

Pistes :
- observation tôt le matin ;
- vêtements extérieurs / humidité ;
- photographie ;
- carnet de couleurs ;
- rencontres locales ;
- textiles de protection ;
- aucune “technique couture” automatique tirée de la pêche.

## NOVEMBRE

Rythme dominant : intérieur, artisanat, préparation fêtes.

Pistes :
- ateliers ;
- cadeaux / accessoires ;
- bijoux ;
- petites séries ;
- recherche matière ;
- commandes de décembre ;
- préparation des événements de Bresse ;
- clientèle soirée / réception.

## DÉCEMBRE

ÉVÉNEMENT RÉEL MAJEUR : Glorieuses de Bresse.

Ces concours existent depuis le XIXe siècle et se déroulent en décembre dans plusieurs communes de Bresse. Pour 2026, Ain Tourisme annonce notamment Pont-de-Vaux, Montrevel-en-Bresse et Bourg-en-Bresse à des dates différentes.

Gameplay possible :
- affluence et changement d’ambiance ;
- hôtels / restauration / presse locale ;
- tenues de réception ;
- clientes liées aux concours et événements ;
- photographie ;
- commandes de fête ;
- habillage de personnes impliquées dans des cérémonies locales ;
- inspiration sur présentation, rituel, blanc / bleu / rouge et textiles d’emballage uniquement si traité de manière documentée et non caricaturale.

Rythme général : forte période de fête, gala, cadeaux, soirée et commandes urgentes.

# 5 — SAISONNALITÉ DES MATIÈRES

Le jeu ne doit pas prétendre qu’une matière réelle n’existe physiquement qu’une saison si ce n’est pas vrai. La saisonnalité peut venir plutôt de :

- arrivages ;
- collections fournisseurs ;
- besoins de clientèle ;
- expositions ;
- disponibilité d’un artisan ;
- événements ;
- ventes temporaires ;
- inspirations paysagères.

Exemples Ain :
- hiver : laine / maille / protection / matières techniques ;
- printemps : étoffes cérémonie, transparence, couleurs végétales ;
- été : matières légères, accessoires festival, tissus de cérémonie ;
- automne : velours, soie, matières texturées, teintes eau / terre / forêt ;
- décembre : matières de soirée, accessoires, finitions précieuses.

# 6 — TOURISME ET AFFLUENCE

Zones particulièrement sensibles à l’affluence saisonnière :
- Pérouges ;
- Dombes ;
- Pays de Gex / Monts Jura ;
- lacs et Haut-Bugey ;
- Bourg lors de grands événements ;
- Ambronay pendant le festival.

Effets possibles :
- davantage de personnes de passage ;
- hôtels plus sollicités ;
- transports plus chargés ;
- nouvelles clientes temporaires ;
- rencontres internationales / interrégionales ;
- prix et disponibilités de certains services ;
- davantage d’opportunités photo / événement ;
- moindre probabilité de recroiser une personne de passage hors saison.

---

# 7 — ÉVÉNEMENTS FICTION GAMEPLAY AUTORISÉS

À utiliser seulement comme événements procéduraux clairement fictifs et cohérents avec le territoire :

- appel à créateurs pour une présentation collective à Bourg ;
- photographe cherchant une collaboration à Pérouges ;
- besoin urgent d’un accessoire pour un musicien à Ambronay ;
- petite série d’ornements à Oyonnax ;
- artisan du Bugey ouvrant son atelier pour une journée ;
- vente de fonds / départ à la retraite d’un artisan ;
- costume pour un spectacle local ;
- exposition textile temporaire à Jujurieux ;
- shooting mode au bord d’un étang en Dombes ;
- événement caritatif ou gala local ;
- commande de cérémonie groupée ;
- résidence artistique ;
- recherche de costumier pour une production locale.

Aucun événement fictif ne doit usurper le nom d’une véritable structure ou personne sans vérification et décision explicite.

---

# 8 — RÈGLE DE REVISITE SAISONNIÈRE

Un même lieu doit pouvoir avoir une valeur différente selon la période.

Exemples :
- Dombes en avril ≠ Dombes en octobre ;
- Ambronay hors festival ≠ pendant le festival ;
- Pérouges en hiver ≠ en pleine saison touristique ;
- Pays de Gex en été ≠ en hiver ;
- Bourg en semaine ordinaire ≠ pendant les Glorieuses ;
- Jujurieux lors d’une visite patrimoniale ≠ lors d’une exposition ou rencontre spécialisée.

La mémoire du jeu doit donc enregistrer non seulement “lieu visité”, mais aussi contexte, saison et événement lorsqu’ils sont significatifs.
