# HAUTE COUTURE LIVE — AIN (01) — ATELIER / BOOK / SHOOTINGS / DÉCOUVERTES

Statut : chantier actif sur la branche `territoires-france`.

Cette fiche applique la checklist territoriale officielle à l’Ain. Elle ne crée pas de nouvelle interface : elle prépare le contenu à injecter dans les systèmes Atelier, Book, photographie, carrière et mémoire territoriale.

Règle : une source réelle reste une source culturelle/documentaire. Sa traduction créative n’est jamais automatique.

---

# 1 — CONTENU ATELIER : GRANDES FAMILLES DE DÉCOUVERTE

## Bresse / Bourg

Sources : costume bressan, coiffes, dentelle noire, émaux bressans, fermes bressanes, bocage, Monastère royal de Brou.

Peut nourrir :
- silhouettes de cérémonie ;
- superpositions ;
- systèmes de tablier / pans ;
- noir, blanc, transparence, dentelle ;
- verticalités issues des coiffes ;
- détails émaillés ;
- broches, bijoux, petits accessoires ;
- rythmes architecturaux ;
- couleurs de terres, toitures, pierre et végétal.

## Dombes

Sources : étangs, roseaux, oiseaux, reflets, brouillards, pêche d’étang, architecture de Dombes.

Peut nourrir :
- palettes d’eau et de brume ;
- surfaces changeantes ;
- transparence / moiré / reflet ;
- couches protectrices ;
- silhouettes de marche et d’extérieur ;
- recherches photographiques ;
- volumes inspirés par oiseaux et végétal uniquement lorsque pertinent.

## Bugey / Jujurieux / Cerdon

Sources : Soieries Bonnet, archives d’échantillons, soie, velours, mémoire ouvrière, cuivre et dinanderie, relief et vigne.

Peut nourrir :
- culture approfondie de la soie ;
- velours ;
- construction à partir d’archives ;
- détails métalliques ;
- fermoirs ;
- broches et bijoux ;
- surfaces martelées ;
- contrastes textile / métal ;
- palettes de vallées, cuivre, vigne, pierre.

## Haut-Bugey / Oyonnax

Sources : peignes, ornements de coiffure, lunetterie, acétate, plasturgie, design industriel, outils et machines.

Peut nourrir :
- accessoires ;
- bijoux ;
- lunettes ;
- pièces rigides ;
- transparences ;
- effets écaille / marbré / translucide ;
- structures moulées ou découpées ;
- recherche de fermeture et assemblage ;
- petite série et prototype.

## Pays de Gex / Monts Jura

Sources : altitude, froid, neige, frontière, déplacements, sports de montagne, lumière et relief.

Peut nourrir :

## Pérouges / Plaine de l’Ain

Sources : cité médiévale, pierre, pavés, ferronnerie, portes, architecture, fréquentation touristique, proximité lyonnaise.

## Revermont

Sources : Meillonnas, faïence, argile, villages, chemins, jardins, architecture rurale, musée du Revermont.

# 2 — RARETÉ DES DÉCOUVERTES

Chaque ressource doit pouvoir être classée :

## Commune
Accessible publiquement et fréquemment.
Exemple : observation de paysage, architecture visible, musée ouvert au public.

## Inhabituelle
Nécessite une visite ciblée, un horaire, un événement ou une bonne adresse.

## Rare
Nécessite une rencontre, une recommandation, une visite spéciale, un stock limité ou une période particulière.

## Très rare
Nécessite un réseau professionnel établi, une collection privée, un artisan spécialisé ou une opportunité limitée.

## Exceptionnelle
Liée à une pièce d’archive, une commande, une transmission, un événement unique ou une relation longue.

La rareté ne doit pas être seulement monétaire.

# 6 — EXPOSITIONS TEMPORAIRES ET MONDE CHANGEANT

Les musées de l’Ain ne doivent jamais être considérés comme statiques.

La Direction des Patrimoines et des Musées propose des expositions temporaires et itinérantes, ce qui donne une base réaliste pour :
- nouvelles raisons de revenir ;
- thèmes annuels ;
- conférences ;
- visites particulières ;
- résidences artistiques ;
- rencontres ;
- nouvelles références Book.

Exemples documentés récemment :
- « Dessous de campagne » au Domaine des Saveurs en 2026 ;
- défilé « L’envers se montre » associé à cette exposition ;
- ateliers « Travaux d’aiguilles » ;
- exposition sur la vie quotidienne 1930-1950 à Nantua en 2026 ;
- exposition « Jean-Baptiste Tournassoud, reflets de Nature » au musée du Revermont en 2025-2026, puis projet itinérant.

Pour le jeu à long terme :
- événements réels = documentés quand disponibles ;
- années futures inconnues = banque d’expositions FICTION GAMEPLAY cohérentes avec les collections et missions du lieu.

# 8 — RÈGLE DE CONSÉQUENCE

Une découverte importante doit pouvoir avoir au moins une conséquence plausible, mais pas forcément immédiate.

Exemple :

visite des Soieries Bonnet
→ note Book
→ compréhension d’une construction textile
→ plusieurs mois plus tard, création personnelle
→ shooting
→ une personne remarque cette création
→ possibilité professionnelle éventuelle.

Aucune récompense automatique n’est requise à la visite.

---

# 9 — RÈGLE DE REVISITE

Un même lieu peut être revisité parce que :
- nouvelle exposition ;
- saison différente ;
- nouvel événement ;
- personnage désormais connu ;
- accès professionnel acquis ;
- shooting ;
- recherche pour une commande ;
- retour après plusieurs années ;
- mémoire personnelle de Marion.

Le territoire ne doit jamais être consommable en une seule visite.
