# 23 — POINTS CRITIQUES RESTANTS

Avant de qualifier Bourg de “ville territorialement complète”, il reste surtout :

1. confirmer une liste fiable de friperies/vintage ;
2. préciser 3–5 photographes/studios réels vraiment intéressants ;
3. hiérarchiser les hôtels et cafés selon usage narratif réel ;
4. approfondir 2–3 quartiers hors centre ;
5. préciser quelles techniques peuvent réellement être apprises à Bourg, par opposition aux simples inspirations ;
6. vérifier périodiquement le calendrier annuel réel.
