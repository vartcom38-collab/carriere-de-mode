# HAUTE COUTURE LIVE — AIN (01) — BANQUE DE CHANGEMENT DU MONDE 20–30 ANS — V1

But : faire évoluer l’Ain indépendamment de Marion, selon le principe Nîmes ville test. Les changements sont FICTION GAMEPLAY sauf lorsqu’un fait réel daté est explicitement documenté.

Règle : ne jamais faire tout changer à la fois. Les évolutions doivent être rares, cohérentes, mémorisées et parfois réversibles.

---

# OYONNAX / HAUT-BUGEY

Évolutions possibles :
- départ à la retraite d’un technicien ;
- reprise de son activité par un enfant ou ancien apprenti ;
- nouvelle matière recyclée adoptée par un fabricant ;
- fermeture d’un atelier ancien ;
- création d’un petit studio de design indépendant ;
- nouvelle exposition au musée ;
- redécouverte d’archives ou machines ;
- jeune designer local qui devient reconnu ;
- événement professionnel qui gagne ou perd en importance.

Conséquences : nouvelles personnes, nouveaux contacts, disparition d’anciennes ressources, accès différent à la fabrication, Book historique plus riche.

# JUJURIEUX / CERDON / ALBARINE

- nouvelle campagne de restauration patrimoniale ;
- exposition textile temporaire ;
- ancien fonds familial versé à une collection publique ;
- décès ou départ d’un témoin de mémoire ;
- transmission d’un savoir-faire métal ;
- atelier de réemploi qui apparaît dans la vallée ;
- fermeture d’une petite activité ;
- projet culturel sur mémoire ouvrière.

Conséquences : certaines connaissances deviennent plus rares avec le temps ; revenir tôt ou maintenir une relation peut changer ce que Marion connaît vingt ans plus tard.

# DOMBES

- domaine de mariage qui change de propriétaire ;
- nouveau photographe nature ;
- évolution d’un marché saisonnier ;
- nouvelle exposition liée aux étangs ;
- modification d’un itinéraire de visite ;
- jeune organisatrice qui crée son entreprise ;
- brocante saisonnière qui disparaît ou déménage.

# PAYS DE GEX / MONTS JURA

- nouvel acteur culturel transfrontalier ;
- festival qui change d’échelle ;
- atelier couture qui ferme ou devient école associative ;
- nouvelle galerie ;
- changement d’hôtel ou lieu de réception ;
- évolution de l’offre montagne ;
- nouvel itinéraire Genève–Gex utile à la carrière ;
- professionnelle locale qui part travailler à Genève mais reste contact.

# BOURG-EN-BRESSE

- transformation progressive d’un quartier ;
- nouvelle direction dans un lieu culturel ;
- café devenu rendez-vous créatif ;
- studio photo qui ferme ;
- nouvel espace de travail partagé ;
- évolution d’un lieu patrimonial ;
- cliente ancienne dont l’enfant devient cliente à son tour ;
- ancienne concurrente devenue organisatrice/acheteuse.

# BELLEY / BUGEY SUD

- nouveau lieu culturel ;
- changement de programmation ;
- artisan qui transmet ;
- nouvelle activité autour du tourisme ou mariage ;
- évolution des circuits de randonnée/shooting ;
- création d’une résidence artistique.

# PETITS PÔLES

Ambérieu : changement de mobilité, nouveau lieu culturel, fermeture/ouverture de commerce.
Châtillon : marché, patrimoine, brocante ou événement saisonnier qui évolue.
Vonnas : évolution de l’hospitalité et des réceptions.
Valserhône : nouveau projet culturel ou transfrontalier.
Trévoux : nouvelle génération d’artisans d’art.
Revermont : reprise d’un atelier ou disparition d’un artisan.

---

# MÉCANIQUE DE MÉMOIRE

Chaque événement de monde changeant doit produire au minimum :
- date/année ;
- territoire ;
- élément concerné ;
- ancien état ;
- nouvel état ;
- personnes concernées ;
- éventuelles conséquences Atelier/Book/téléphone/agenda/réseau.

Une revisite doit pouvoir afficher la différence : « La dernière fois que tu es venue… » ou « Depuis ton passage… ».

---

# LIMITES

- pas de catastrophe permanente pour faire du contenu ;
- pas de fermeture arbitraire de vrais établissements au présent ;
- pas de faits inventés attribués à de vraies personnes ;
- pas de prestige automatique avec le temps ;
- certains changements doivent être neutres ou même réduire une opportunité.
