# HAUTE COUTURE LIVE — AIN (01) — FIGURES, PROS CRÉATIFS, LIEUX SOCIAUX — COMPLÉMENTS V1

Statut : chantier actif — branche `territoires-france`.

Objectif : fermer plusieurs catégories encore faibles de la checklist officielle : figures locales réelles documentées, professionnels créatifs, lieux sociaux utiles, hôtellerie et fournisseurs complémentaires.

Règle absolue : une personne ou structure réelle est une référence documentée. Elle ne devient jamais automatiquement personnage interactif, employeur, mentor, cliente ou partenaire de Marion.

---

# 1 — FIGURES HISTORIQUES / CULTURELLES RÉELLES À UTILISER COMME RÉFÉRENCES

## Claude-Joseph Bonnet — Jujurieux / Lyon

Rôle documentaire : fondateur de la maison Bonnet en 1810 ; implantation de la manufacture de Jujurieux à partir de 1835.

Intérêt gameplay :
- histoire de l’industrialisation textile ;
- organisation d’une maison de soierie ;
- qualité du fil ;
- rapport Lyon ↔ Jujurieux ;
- mémoire sociale et industrielle.

Usage : référence historique / archives / exposition. Pas de personnage interactif contemporain.

## Ouvrières, tisseuses, gareurs et pensionnaires des Soieries Bonnet

Rôle documentaire collectif : la mémoire du site repose aussi sur les milliers de personnes ayant travaillé dans la manufacture et à domicile.

Intérêt gameplay :
- histoire sociale du vêtement ;
- transmission ;
- gestes ;
- condition ouvrière ;
- écrits et graffitis conservés ;
- différence entre patrimoine luxueux et réalité du travail.

Usage : recherche, Book, exposition, témoignages historiques. Ne pas les réduire à une esthétique romantisée.

## Figures locales contemporaines

À compléter uniquement à partir de sources solides, ville par ville, et de préférence dans les catégories suivantes :
- conservateurs / directeurs culturels ;
- responsables de festivals ;
- artisans d’art reconnus ;
- créateurs ;
- photographes ;
- responsables de manufactures ;
- acteurs de la transmission patrimoniale.

Règle : aucune personne réelle vivante ne reçoit d’histoire fictive personnelle.

# 2 — OYONNAX : PÔLE PROFESSIONNEL + CULTUREL

Le Centre Culturel Aragon regroupe plusieurs services :
- La Scène ;
- cinéma Art & Essai ;
- médiathèque ;
- Musée du Peigne et de la Plasturgie ;
- archives municipales ;
- Café des Artistes.

Intérêt gameplay : cet ensemble peut devenir un vrai nœud de vie culturelle et professionnelle à Oyonnax.

## Café des Artistes

Statut : lieu réel lié au Centre Culturel Aragon.

Utilité :
- avant / après spectacle ;
- rencontre d’un artiste de passage ;
- débrief après exposition ;
- rendez-vous avec un photographe ou designer ;
- lieu de rumeur culturelle ;
- pas de mission automatique.

## La Scène

À utiliser pour :
- spectacle ;
- habillage ;
- costume ;
- rencontres techniques ;
- résidences ;
- événements de carrière selon programmation.

# 3 — JUJURIEUX : PATRIMOINE TEXTILE VIVANT

Les Soieries Bonnet disposent d’une profondeur documentaire exceptionnelle :
- environ 300 000 objets et documents ;
- étoffes ;
- outils de production ;
- archives du monde du travail ;
- iconographie ;
- métiers à tisser ;
- cadres d’impression ;
- mémoire des ouvrières et ouvriers.

Le site propose aussi des contenus saisonniers, par exemple élevage de vers à soie entre juin et octobre et ateliers liés au nourrissage.

Conséquence gameplay :
- Jujurieux doit avoir des raisons de revisite saisonnières ;
- les archives ne sont pas consommées en une visite ;
- certaines recherches doivent nécessiter plusieurs passages ;
- une exposition peut ouvrir une nouvelle piste Book sans débloquer automatiquement une technique Atelier.

# 5 — LIEUX SOCIAUX UTILES

Règle : un café ou restaurant n’entre dans le jeu que s’il a une vraie fonction.

Catégories utiles :
- café de lieu culturel ;
- café historique ;
- lieu fréquenté par professionnels ;
- restaurant/hôtel lié au mariage ;
- lieu de rendez-vous avant événement ;
- lieu de passage en gare ;
- lieu de festival ;
- adresse associée à une tradition locale importante.

Exemple déjà solide : Café des Artistes à Oyonnax.

Les autres lieux doivent être retenus avec parcimonie.

---

# 6 — HÔTELLERIE / PRESTIGE

L’hôtellerie doit être hiérarchisée par usage :

## Fonction voyage
- nuit lors d’un déplacement professionnel ;
- retour tardif impossible ;
- déplacement de plusieurs jours.

## Fonction événementielle
- mariage ;
- réception ;
- gala ;
- conférence ;
- shooting ;
- invités extérieurs.

## Fonction prestige
- clientèle aisée ;
- soirée privée ;
- rendez-vous presse ;
- invité de passage.

Ne pas inventer de palace ou showroom si la ville n’en possède pas.

---

# 7 — FOURNISSEURS / MATIÈRES COMPLÉMENTAIRES

À distinguer :

## Fourniture courante
- mercerie ;
- fil ;
- boutons ;
- entoilage ;
- fermeture ;
- tissu courant.

## Fourniture spécialisée
- acétate / matière rigide à Oyonnax ;
- composants accessoires ;
- soie / mémoire textile à Jujurieux ;
- métal à Cerdon ;
- gemme à Mijoux ;
- émail / bijou en Bresse.

## Fourniture rare
Elle doit dépendre de :
- relation ;
- stock limité ;
- événement ;
- période ;
- commande spéciale ;
- réputation.

---

# 8 — FICTION GAMEPLAY : PERSONNAGES-PONTS

Pour relier les vraies structures sans attribuer des comportements fictifs à des personnes réelles, créer des personnages fictifs comme :
- régisseuse de spectacle ;
- photographe indépendante ;
- habilleuse ;
- libraire patrimoniale ;
- couturière locale ;
- artisan accessoire ;
- chargée d’exposition ;
- organisatrice de mariage ;
- responsable d’un atelier partagé.

Ces personnages peuvent fréquenter des lieux réels, mais leurs contrats et histoires restent fictifs.
