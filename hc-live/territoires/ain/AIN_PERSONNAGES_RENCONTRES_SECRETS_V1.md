# HAUTE COUTURE LIVE — AIN (01) — PERSONNAGES, RENCONTRES, SECRETS

Statut : chantier actif sur `territoires-france`.

Cette fiche applique les sections PERSONNAGES / FIGURES LOCALES / PNJ / RENCONTRES / SECRETS de la checklist territoriale officielle.

Règle absolue :
- le réel documenté sert de contexte, référence ou ancrage culturel ;
- les personnages interactifs de gameplay sont fictifs sauf décision explicite contraire ;
- une personne réelle n’est jamais transformée automatiquement en contact, cliente, mentor, employeur ou personnage interactif.

# 3 — FIGURES RÉELLES : RÈGLE D’USAGE

Le Département dispose de fonds permettant de documenter « mémoire des gens, des lieux et des activités » via écrits, plans, photographies et films.

Usage gameplay recommandé :
- citation dans une exposition ;
- source d’archive ;
- nom dans une chronologie ;
- sujet d’un fonds ;
- contexte culturel ;
- inspiration historique.

À éviter :
- faux dialogue ;
- fausse commande ;
- fausse relation avec Marion ;
- invention de faits biographiques.

# 4 — RENCONTRES LIBRES

Une rencontre libre ne doit pas systématiquement devenir une quête.

Familles de rencontres :
- croiser une personne connue dans un autre lieu ;
- être reconnue après plusieurs visites ;
- entendre une conversation utile ;
- observer un vêtement ou détail ;
- demander une adresse ;
- être présentée à quelqu’un ;
- revoir une ancienne cliente ;
- croiser un professionnel à un événement ;
- rencontrer un artiste de passage ;
- tomber sur un artisan pendant une démonstration ;
- discuter avec une personne lors d’une attente gare / café / festival ;
- revoir une ancienne connaissance de plusieurs années auparavant.

Chaque rencontre doit pouvoir finir par :
- rien ;
- simple mémoire ;
- adresse ;
- recommandation ;
- relation ;
- idée ;
- invitation ;
- piste professionnelle ;
- future cliente ;
- future collaboration.

Aucun résultat n’est garanti.

# 6 — SECRETS TERRITORIAUX

Catégories de secrets possibles :

## Adresse discrète
Découverte par recommandation, habitude ou observation.

## Fonds documentaire peu visible
Découvert par archiviste, conservateur, professeur, relation professionnelle.

## Artisan spécialisé
Découvert par bouche-à-oreille.

## Matière ou composant rare
Découvert via fournisseur / industriel / artisan.

## Lieu de shooting
Découvert par photographe, habitant ou exploration.

## Événement privé
Découvert par invitation ou relation.

## Vente ponctuelle
Découverte via rumeur, affiche, téléphone ou relation.

## Personne-clé
Découverte parce qu’un contact recommande un autre contact.

## Histoire locale
Découverte dans archives, musée, discussion, carnet ancien.

## FICTION GAMEPLAY : succession d’atelier
Un artisan se retire et transmet ou vend matériel / fonds / savoir-faire. Cet événement doit être rare et cohérent sur plusieurs années.

# 8 — MÉMOIRE DES PERSONNES

Chaque personnage persistant doit conserver :
- première rencontre ;
- lieu de rencontre ;
- dernière interaction ;
- sujets discutés ;
- aide donnée / reçue ;
- recommandation ;
- collaboration ;
- tension ;
- commande ;
- invitations ;
- lieux communs ;
- événements partagés ;
- évolution professionnelle éventuelle.

Après plusieurs années, un personnage peut :
- changer de poste ;
- déménager ;
- devenir plus influent ;
- se reconvertir ;
- transmettre son activité ;
- perdre le contact avec Marion ;
- revenir dans sa vie.
