# HAUTE COUTURE LIVE — BOURG-EN-BRESSE — COMPLÉMENTS V2

Statut : approfondissement de la checklist ville sur la branche `territoires-france`.

Règle : les faits réels documentés restent séparés de la FICTION GAMEPLAY.

---

# 1 — ZONES / QUARTIERS UTILES AU GAMEPLAY

## Cœur historique / quartiers anciens

Rôle : patrimoine, marche, observation, photographie, clientèle de proximité, boutiques, rencontres culturelles.

Éléments à exploiter :
- maisons médiévales et anciennes rues ;
- hôtels particuliers ;
- rues piétonnes ;
- détails de façades, ferronneries, escaliers, menuiseries ;
- proximité commerces / cafés / lieux culturels.

Gameplay possible :
- recherche visuelle ;
- repérage shooting ;
- rendez-vous cliente ;
- rencontre fortuite ;
- brocante / événement temporaire ;
- adresse recommandée ;
- revisite saisonnière.

## Axe Alsace-Lorraine

Rôle : liaison entre anciens quartiers et développement moderne de la ville.

Intérêt :
- avenue structurante ;
- immeubles de pierre ;
- contraste urbain avec rues anciennes ;
- direction artistique plus urbaine et verticale.

## Plateau / Bel-Air

Rôle : mémoire ferroviaire et développement de nouveaux quartiers depuis l’arrivée du train.

Intérêt gameplay :
- gare ;
- transit ;
- personnages de passage ;
- départs professionnels ;
- logistique de commandes ;
- réseau vers Lyon / Paris / Genève.

## Brou / secteur du monastère

Rôle : patrimoine majeur, musée, expositions, tourisme culturel, cérémonies, photo et événements.

## Secteurs résidentiels / périphériques

À traiter progressivement selon besoin de logement, commerces, vie quotidienne et clientèle de proximité. Aucun quartier résidentiel ne doit être ajouté uniquement pour remplir la carte.

# 3 — PHOTOGRAPHIE / STUDIOS

La ville possède des photographes professionnels actifs, notamment portrait, mariage, famille et studio.

Pour intégration :
- ne retenir qu’un professionnel réel après vérification individuelle ;
- ne jamais présumer qu’il travaille dans la mode ;
- distinguer portrait/mariage/reportage de véritable direction éditoriale mode.

Familles de gameplay :
- portrait cliente ;
- photo de mariage ;
- shooting lookbook ;
- test en studio ;
- photo extérieure dans quartiers anciens ;
- repérage Brou ;
- collaboration avec photographe fictif persistant ;
- constitution progressive d’un réseau photo.

FICTION GAMEPLAY recommandée : créer quelques photographes persistants fictifs spécialisés mode/portrait/événement, plutôt que de faire jouer ce rôle à des professionnels réels sans base documentaire.

# 15 — MANQUES ENCORE À TRAITER POUR FERMER BOURG

- vérifier plusieurs friperies / vintage actuelles ;
- documenter au moins quelques photographes réels individuellement ;
- lister les autres merceries / fournisseurs après vérification ;
- documenter les principaux hôtels utiles ;
- sélectionner quelques cafés / restaurants à vraie valeur sociale ou patrimoniale ;
- vérifier calendrier annuel précis 2026/2027 puis transformer en moteur récurrent ;
- compléter les personnages fictifs avec fiches individuelles ;
- produire une banque de 30 à 50 briefs de missions déterministes ;
- produire une banque de secrets / rumeurs ;
- lier chaque découverte aux systèmes Atelier / Book / téléphone / agenda / carrière ;
- vérifier que chaque élément garde une raison de revisite.

Bourg-en-Bresse n’est donc pas encore déclarée terminée, mais la ville possède désormais une structure de contenu beaucoup plus dense et exploitable.
