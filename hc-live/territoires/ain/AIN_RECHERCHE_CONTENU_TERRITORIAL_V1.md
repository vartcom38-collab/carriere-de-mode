# HAUTE COUTURE LIVE — AIN (01) — RECHERCHE & CONTENU TERRITORIAL

Statut : chantier actif sur la branche `territoires-france`.

Cette fiche applique la checklist territoriale officielle du projet à l’Ain. Elle complète les systèmes déjà existants (carte, personnalités communales, événements vivants, mémoire personnelle, découverte progressive, vie locale récurrente) sans les remplacer.

Règle : le réel documenté et la FICTION GAMEPLAY restent séparés.

---

# 1 — IDENTITÉ DU DÉPARTEMENT DANS AUVERGNE-RHÔNE-ALPES

## Position et diversité interne

L’Ain doit être traité comme un département très contrasté plutôt que comme une identité unique. Pour le gameplay, on retient les bassins déjà structurés dans le jeu :

- Bresse · Bourg ;
- Dombes ;
- Bugey · Cerdon · Jujurieux ;
- Haut-Bugey · Oyonnax ;
- Pays de Gex · Monts Jura ;
- Pérouges · Plaine de l’Ain ;
- Revermont.

Ces bassins ne sont pas des niveaux de prestige. Ils donnent des rythmes, des matières, des paysages, des traditions, des métiers et des types de rencontres différents.

## Grande lecture créative

L’Ain peut nourrir une carrière de mode par plusieurs portes d’entrée distinctes :

- patrimoine textile et soierie ;
- histoire ouvrière et industrielle ;
- accessoires et ornements ;
- matériaux plastiques et prototypage ;
- métal et dinanderie ;
- faïence et iconographie décorative ;
- pierre et lapidaire ;
- costumes et parures de Bresse ;
- paysages d’eau de la Dombes ;
- montagne, protection et mouvement ;
- patrimoine médiéval et architecture ;
- villages, bocage et artisanat rural.

Le département doit donc produire plusieurs familles visuelles, jamais une seule palette “Ain”.

- Glorieuses de Bresse et effets saisonniers.

### Oyonnax
Rôle : industrie, accessoire, peigne, lunetterie, matières plastiques, design, prototypage.

À documenter en profondeur :

- Grande Vapeur / patrimoine industriel ;
- entreprises et savoir-faire encore actifs ;
- matériaux anciens et modernes ;

### Jujurieux

À documenter en profondeur :

### Gex / Pays de Gex
Rôle : montagne, frontière, clientèle internationale et transfrontalière, mobilité, vêtement de protection et de mouvement.

### Belley / Bugey Sud
Rôle : patrimoine, vallée, relief, liens avec territoires du Bugey, cérémonies et réseau local.

## Niveau C — petites communes stratégiques

À rechercher progressivement selon présence d’un savoir-faire, d’un musée, d’un paysage, d’une archive, d’un événement ou d’une ressource rare. Une petite commune n’est jamais éliminée uniquement à cause de sa population.

# 3 — HISTOIRE DU VÊTEMENT, MODE ET PARURE

## Bresse — costume et identité

SOURCE CULTURELLE RÉELLE

Le costume bressan constitue une source importante mais doit être traité avec précision : les formes variaient selon sous-territoires, niveau social et usages. Les collections départementales conservent costumes, coiffes, chapeaux, tabliers, châles, sabots ouvragés et éléments de parure.

Éléments particulièrement intéressants :
- grand chapeau bressan à cheminée ;
- longs pans de dentelle noire ;
- tablier / devanti ;
- châle ou pointe de Bresse ;
- coiffes liées aux âges et circonstances de vie ;
- sabots décorés ;
- émaux bressans ;
- broches, bagues et colliers.

TRADUCTIONS CRÉATIVES POSSIBLES

Sans recopier le costume :
- travail de verticalité à partir des coiffes ;
- noir / dentelle / transparence ;
- contraste entre vêtement quotidien et vêtement de fête ;
- systèmes de pans, tablier, superposition ;
- bijoux et petites pièces émaillées ;
- recherches sur code social et vêtement de cérémonie.

## Oyonnax — ornement de coiffure et accessoire

SOURCE CULTURELLE / INDUSTRIELLE RÉELLE

Les collections du Musée du Peigne et de la Plasturgie documentent notamment :
- peignes ;
- ornements de coiffure ;
- lunettes ;
- anciennes matières plastiques ;
- objets de mode et design ;
- outils et machines ;
- robes et accessoires liés à l’histoire de la création moderne.

TRADUCTIONS CRÉATIVES POSSIBLES

- accessoires cheveux ;
- bijoux et fermoirs ;
- lunettes / formes faciales ;
- structures rigides ;
- transparence / translucidité ;
- contrastes mat / brillant ;
- pièces moulées ou découpées ;
- petite série.

## Jujurieux / Bugey — vêtement et industrie textile

La soierie ne doit pas être réduite à une simple “matière luxueuse”. Il faut traiter :
- organisation du travail ;
- qualité du fil ;
- tissage ;
- étoffes pour habillement ;
- velours façonnés ;
- travail à domicile ;
- place des ouvrières ;
- circulation Lyon ↔ Jujurieux ↔ marchés internationaux.

# 4 — TEXTILE, MATIÈRES ET FOURNITURES

## Soie — Jujurieux et Bugey

Niveau : exceptionnel pour la mémoire textile du département.

À intégrer :
- soie ;
- fil ;
- étoffes unies ;
- noir historique ;
- velours façonné ;
- chaînes de préparation ;
- archives d’échantillons ;
- outils et machines ;
- fournisseurs / réseaux historiques.

Accès gameplay possible :
- public au début pour patrimoine / musée ;
- recherche documentaire plus poussée ensuite ;
- contacts techniques après relation ;
- collaborations spécialisées à carrière plus avancée.

## Schappe et déchets de soie — vallée de l’Albarine

À approfondir : histoire du traitement de la schappe et liens avec Saint-Rambert-en-Bugey / Tenay.

Potentiel :
- fibres recyclées / revalorisation ;
- histoire industrielle ;
- réemploi comme thème de création ;
- comparaison entre luxe de la soie et récupération de matière.

## Matières plastiques / acétate — Oyonnax

Niveau : spécialisé.

À traiter :
- celluloïd historique ;
- galalithe ;
- bakélite et matières synthétiques ;
- acétate de cellulose ;
- plastique recyclé ;
- usages mode : peigne, lunetterie, bijoux, accessoires.

Gameplay :
- bibliothèque matière ;
- comparaison rigidité / transparence / épaisseur ;
- prototype accessoire ;
- collaboration fabrication ;
- petite série ;
- questionnement sur matières anciennes vs recyclées.

## Métal / cuivre — Cerdon

Niveau : spécialisé.

À traiter :
- cuivre ;
- feuilles de métal ;
- martelage ;
- dinanderie ;
- emboutissage ;
- repoussage ;
- orfèvrerie ;
- chaudronnerie.

Traductions possibles :
- ornements ;
- plaques ;
- fermoirs ;
- bijoux ;
- détails structurés ;

## Argile / faïence — Meillonnas

Niveau : patrimoine local spécialisé.

Usage mode indirect mais riche pour :
- motifs ;
- bordures ;
- palettes ;
- fleurs stylisées ;
- dessin d’accessoires ;
- direction artistique.

## Pierre / gemmes — Mijoux

Niveau : spécialisé / rare selon matière.

À traiter :
- taille de pierres fines et précieuses ;
- minéraux ;
- outillage ;
- gestes de taille ;
- bijou et détail précieux.

# PREMIÈRES CONSÉQUENCES GAMEPLAY À CONSERVER

Ces recherches doivent alimenter les systèmes existants, sans missions automatiques :

- Atelier : matières, accessoires, textures, techniques documentées ;
- Book : archives, lieux, palettes, recherches, photographies ;
- relations : artisans, conservateurs, techniciens, commerçants, organisateurs ;
- carrière : collaborations possibles seulement après contexte crédible ;
- carte : découverte progressive ;
- mémoire : les lieux/personnes déjà connus restent connus ;
- revisite : nouveaux niveaux de lecture après plusieurs visites ;
- saisonnalité : certains savoir-faire et paysages prennent une autre valeur selon la période.
