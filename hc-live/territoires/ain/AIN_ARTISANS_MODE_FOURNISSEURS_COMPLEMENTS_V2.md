# HAUTE COUTURE LIVE — AIN — ARTISANS / MODE / FOURNISSEURS — COMPLÉMENTS V2

Branche : `territoires-france`

Objectif : réduire les catégories encore rouges de la checklist officielle : artisans d'art, textile, couture, tissage, dentelle, maroquinerie, bijouterie, photographie, fournisseurs et acteurs de fabrication.

Règle : ces structures sont des références réelles documentées. Elles ne deviennent jamais automatiquement employeurs, clientes, mentors ou partenaires de Marion. Toute interaction scénarisée avec elles doit être séparée et, si fictive, marquée **FICTION GAMEPLAY**.

---

# 1 — ASSOCIATION DES MÉTIERS D'ART DE L'AIN

L'association départementale constitue un bon index de savoir-faire présents dans l'Ain. Parmi les métiers recensés et directement intéressants pour Haute Couture Live :

- maroquinerie ;
- stylisme ;
- dentelle aux fuseaux ;
- couture ;
- tissage traditionnel ;
- tailleur sur mesure ;
- lunetterie ;
- photographie ;
- bijouterie ;
- joaillerie ;
- émaux bressans ;
- ferronnerie / métallerie ;
- verre ;
- céramique ;
- tapisserie d'ameublement.

## Utilité jeu

Cette association ne doit pas devenir un distributeur de "quêtes". Elle sert à :
- identifier des métiers réellement présents ;
- territorialiser les savoir-faire ;
- créer des événements de rencontre plausibles ;
- alimenter les Journées Européennes des Métiers d'Art / salons / démonstrations lorsqu'ils sont documentés ;
- construire des personnages fictifs inspirés de métiers réels sans copier des personnes réelles.

# 7 — AUTRES MÉTIERS D'ART UTILES INDIRECTEMENT

- tapissier d'ameublement : compréhension des tissus lourds, structure, garnissage ;
- ferronnerie / métallerie : accessoire et scénographie ;
- verre : lumière, bijou, accessoire ;
- céramique : surface, motif, palette ;
- reliure : Book, archives, présentation de collection ;
- sculpture pierre / métal : volume, poids, structure ;
- cannage / paillage : tressage, rythme, matière naturelle.

Ne pas convertir chaque métier en technique couture.

---

# 8 — ÉVÉNEMENTS / RÉSEAU ARTISANAL

L'Association des Métiers d'Art de l'Ain indique organiser ou promouvoir des manifestations dédiées, notamment une Biennale des Métiers d'Art de l'Ain.

À chaque année de jeu :
- vérifier l'existence réelle / calendrier avant date précise ;
- si le moteur a besoin d'une manifestation supplémentaire, créer une **FICTION GAMEPLAY** clairement séparée.
