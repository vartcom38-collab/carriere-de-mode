# HAUTE COUTURE LIVE — AIN (01) — SYNTHÈSE FINALE PRÊTE INTÉGRATION

Référentiel éditorial : Nîmes ville test + checklist territoriale officielle.
Branche : territoires-france.

## 1 — RÔLE DU DÉPARTEMENT

L’Ain fonctionne comme un territoire de carrière complet et non comme une simple collection de points de carte.

Axes majeurs :
- Bourg-en-Bresse / Bresse : patrimoine, costume, cérémonie, scène, archives, clientèle locale et institutionnelle ;
- Oyonnax / Haut-Bugey : peigne, accessoire, plasturgie, lunetterie, prototype, petite série, industrie et design ;
- Jujurieux / Cerdon / Albarine : soie, schappe, cuivre, mémoire ouvrière, transformation et récupération ;
- Dombes : eau, brume, oiseaux, mariage, tourisme nature, photographie, saisonnalité ;
- Pays de Gex / Monts Jura : frontière, Genève, clientèle internationale, montagne, réception, événements et mobilité ;
- Pérouges / Plaine : patrimoine, photo, mariage, festivals, seconde main, tourisme ;
- Ambronay : spectacle vivant, résidence, musique et costume ;
- Nantua : lac, patrimoine, recherche historique et mémoire ;
- Revermont / Meillonnas / Trévoux : faïence, argile, fil d’or et d’argent, artisanat et patrimoine ;
- Belley / Bugey Sud : montagne, réception, tourisme, culture et lien Savoie ;
- pôles secondaires : Ambérieu, Châtillon-sur-Chalaronne, Vonnas, Saint-Rambert-en-Bugey, Valserhône.

## 3 — RÈGLE RÉEL / FICTION

- Lieu réel : documenté comme contexte, ressource, patrimoine ou possibilité de visite.
- Professionnel réel : jamais transformé automatiquement en employeur, mentor, client ou partenaire.
- Personnage interactif : fictif, sauf simple apparition documentaire explicitement contextualisée.
- Mission : fiction gameplay ancrée dans une raison territoriale réelle.
- Événement daté : doit être revalidé pour l’année jouée.

## 4 — PERSONNAGES

## 8 — SAISONNALITÉ

Le calendrier Ain est consolidé janvier → décembre avec :
- montagne/hiver ;

- festivals/tourisme/shootings l’été ;

Le département dispose d’une banque d’évolution 20–30 ans :

- transmission ;
- retraite ;
- nouvel apprenti ;
- changement de programmation culturelle ;
- nouvelle exposition ;
- événement qui grossit ou disparaît ;
- nouveau commerce ;
- changement de marché ;
- évolution d’un quartier ;
- nouveaux matériaux ;
- clients devenus prescripteurs ;
- enfants d’anciennes clientes ;
- concurrents devenus partenaires ou institutions.

## 12 — STATUT INTÉGRATION

Le département peut maintenant être considéré comme :

**PRÊT POUR INTÉGRATION TERRITORIALE V1**

Cela signifie :
- tous les grands systèmes territoriaux existent ;
- les principaux pôles sont différenciés ;
- les connexions aux systèmes globaux sont définies ;
- les banques de contenu essentielles existent ;
- les catégories encore incomplètes sont des enrichissements, pas des blocages structurels.

## 13 — ENRICHISSEMENTS NON BLOQUANTS

À poursuivre lors des passes ultérieures :
- davantage de merceries/fournisseurs réels par bassin ;
- studios/pros photo réels spécialisés ;
- sélection plus fine de cafés/hôtels ;
- petites communes additionnelles ;
- enrichissement continu des figures historiques/culturelles ;
- nouvelles missions et secrets ;
- revalidation annuelle des événements réels ;
- géographie urbaine encore plus fine de certaines villes.

## 14 — RÈGLE DE CLÔTURE

L’Ain n’est pas « fini pour toujours » : il est **suffisamment documenté et structuré pour être intégré au jeu**, puis enrichi au fil du développement.

La réussite n’est pas d’avoir tout listé. La réussite est qu’une créatrice puisse y vivre, travailler, rencontrer, apprendre, échouer, revenir, évoluer et y construire une carrière pendant des années sans que le territoire paraisse figé ou interchangeable.
