3. Clémence Borel — opticienne créative ; élégante, précise ; ouvre clientèle accessoire/lunetterie.
4. Noa Vannier — photographe produit ; discret ; fréquentation studios, lieux industriels et événements.
5. Irina Lopes — acheteuse indépendante ; mobile entre Oyonnax, Lyon, Genève ; sensible aux petites séries.
6. Éric Gallet — ancien outilleur ; mémoire industrielle ; peut recommander ateliers mais pas donner de mission automatique.
7. Lise Perrin — jeune styliste concurrente ; ambitieuse ; relation évolutive sur plusieurs années.
8. Yuna Michel — cliente locale travaillant dans l'industrie ; demandes fonctionnelles puis cérémonies.

## Vie temporaire
- démonstration matière ;
- journée portes ouvertes ;
- table d'échantillons ;
- appel à prototype ;
- exposition design ;
- arrivée d'un acheteur ;
- vente de composants ;
- présentation d'un nouveau matériau ;
- rumeur d'un atelier qui cherche un collaborateur ;
- ancien stock remis en circulation.

## 12 briefs
Début :
1. transformer un accessoire rigide existant sans en changer la fonction ;
2. concevoir une pochette compatible avec une tenue industrielle chic ;
3. préparer un moodboard autour des transparences d'acétate ;
4. retoucher une tenue pour une remise de prix locale.

Développement :
5. dessiner un accessoire cheveux pouvant être prototypé localement ;
6. créer une mini-série de détails de fermeture ;
7. travailler une tenue coordonnée à une monture de lunettes ;
8. préparer un prototype pour présentation professionnelle.

Confirmée :
9. capsule accessoire + vêtement avec partenaire de fabrication ;
10. habillage d'une invitée pour événement design ;
11. direction artistique d'un shooting industriel ;
12. pièce manifeste intégrant structure rigide sans imitation de plastique décoratif gratuit.

## Rumeurs / secrets
- ancien nuancier matière conservé par un retraité ;
- lot de composants jamais commercialisés ;
- atelier acceptant de très petites séries ;
- ancienne photothèque d'entreprise ;
- moule ou outil intéressant seulement comme référence ;
- rendez-vous informel entre fabricants ;
- contact vers Lyon ou Genève ;
- jeune entreprise expérimentant du recyclé.

## Atelier
- MATERIAL_KNOWLEDGE : acétate, rigidité, transparence ;
- TECHNIQUE_OBSERVED : moulage, découpe, polissage ;
- DESIGN_REFERENCE : peigne, lunette, accessoire ;
- COLLAB_CAPABILITY : prototypage externe ;
- CRAFT_CONTACT : fabricant / technicien.

## Book
- recherches matière ;
- photos de détails industriels ;
- prototype ;
- collaboration ;
- série accessoire ;
- évolution d'une idée sur plusieurs années.

## Revisites
Début : musée et observation. Milieu : réseau de fabrication. Confirmée : commande petite série. Avancée : transmission, jury, collaboration avec nouvelle génération.
