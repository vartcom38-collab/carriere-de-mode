# 1 — IDENTITÉ GÉNÉRALE

Le Puy-de-Dôme doit fonctionner comme un département à fortes ruptures internes :
- Clermont-Ferrand : textile contemporain, culture, photographie, recherche, vie urbaine ;
- Thiers : métal, précision, design, coutellerie, artisanat et industrie ;
- Riom : patrimoine, archives, manufacture, ville de recherche ;
- Issoire : basse Auvergne, patrimoine, clientèle locale et cérémonielle ;
- Volvic : pierre volcanique, lave émaillée, artisanat ;
- Sancy / Le Mont-Dore / La Bourboule : thermalisme, Belle Époque, montagne, saisonnalité ;
- Orcines / Chaîne des Puys : paysage, matière, climat, photographie ;
- Gergovie : archéologie, costume historique documenté, paysage ;
- Ambert / Livradois-Forez : papier chiffon, artisanat, transmission.

Aucun pôle ne doit reproduire Clermont sous une autre peau.

# 4 — MISSIONS / COMMANDES

Banque V1 : 48 briefs transversaux + briefs déjà contenus dans les fiches villes.

Répartition :
- début : retouche, dépannage, petit shooting, recherche, cérémonie simple, achat matière, réparation ;
- développement : mini-capsule, collaboration locale, événement, photo éditoriale, client régulier, projet culturel ;
- confirmée : commande de scène, série limitée, événement important, collaboration artisanale, clientèle exigeante ;
- avancée : jury, transmission, exposition, direction artistique, commande patrimoniale contemporaine, projet multi-territoires.

Les briefs sont filtrés par mémoire anti-redondance.

---

# 5 — ÉVÉNEMENTS — RÈGLE 2026 → 2056

Les événements 2026 servent uniquement de base réelle documentée.

Pour les années futures :
- nouvelle édition ;
- thème différent ;
- taille différente ;
- lieux différents ;
- participants différents ;
- possibilité d'année blanche ;
- évolution / fusion / disparition / renaissance ;
- événement concurrent possible.

Le jeu compare l'édition aux expériences antérieures de Marion.

Si une combinaison lieu + mission + client + matière + résultat ressemble trop à une expérience déjà vécue, le contenu doit varier ou ne pas produire de mission.

Exemples de familles :
- Biennale textile ;
- Coutellia ;
- événements thermaux ;
- patrimoine ;
- brocantes ;
- marchés ;
- festivals culturels ;
- ateliers d'artisans ;
- manifestations photo ;
- expositions temporaires.

# 10 — SAISONNALITÉ
