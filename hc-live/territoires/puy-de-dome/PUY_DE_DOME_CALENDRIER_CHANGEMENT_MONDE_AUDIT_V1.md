# 2 — MONDE CHANGEANT SUR 20–30 ANS

## Artisans
- retraite ;
- transmission à un enfant ou apprenti ;
- fermeture sans repreneur ;
- nouvel atelier ;
- changement de spécialité ;
- passage d’un atelier individuel à un collectif ;
- artisan rencontré jeune qui devient référence régionale.

## Culture / textile
- biennale ou festival qui change d’échelle ;
- nouvelle direction artistique ;
- exposition temporaire devenue événement marquant du Book ;
- nouveau lieu culturel ;
- ancien lieu réaffecté ;
- partenariats interrégionaux ou internationaux variables.

## Thermalisme / montagne
- hôtel rénové ;
- établissement fermé ;
- clientèle vieillissante remplacée par nouvelle génération ;
- changements de fréquentation ;
- évolution climatique influençant saison de neige et types de séjour ;
- nouvelles habitudes touristiques.

## Commerce / seconde main
- brocanteur qui cesse ;
- friperie qui ouvre ;
- marché déplacé ;
- plateforme ou collectif local qui apparaît ;
- succession familiale créant stock exceptionnel temporaire.

## Personnages
- cliente de 25 ans devient mère puis revient pour mariage d’un enfant ;
- jeune designer devient concurrente puis alliée ;
- apprentie de Thiers ouvre son atelier ;
- photographe change de ville mais garde contact ;
- médiatrice devient directrice ;
- hôtelier transmet son établissement ;
- organisatrice d’événements prend de l’importance.

## Réputation de Marion
Le territoire ne réagit pas pareil à 22, 32, 42 ou 52 ans :
- inconnue : accès public, petits clients, observation ;
- établie : recommandations, collaborations, événements ;
- reconnue : projets importants, presse, invitations ;
- avancée : jurys, transmission, rétrospectives, anciennes clientes et archives de sa propre carrière.
