# IDENTITÉ

Thiers = métal + coutellerie + design + artisanat + geste + précision + ville en pente + patrimoine industriel.

La ville ne doit pas devenir une caricature « couteau = mode ». Son intérêt pour Marion passe par :
- compréhension des matériaux ;
- accessoires ;
- fermoirs ;
- pièces métalliques ;
- design d’objet ;
- collaborations ;
- culture du geste et de la précision.

# ATELIER

Sorties :
- MATERIAL_KNOWLEDGE ;
- TECHNIQUE_OBSERVED ;
- DESIGN_REFERENCE ;
- CRAFT_CONTACT ;
- COLLAB_CAPABILITY.

Peut apprendre :
- vocabulaire matériau ;
- contraintes de poids ;
- surfaces ;
- type de fixation simple ;
- logique de prototype en collaboration.

Ne peut pas apprendre automatiquement :
- forge complexe ;
- trempe ;
- coutellerie complète ;
- gravure experte ;
- métiers nécessitant apprentissage spécialisé.
