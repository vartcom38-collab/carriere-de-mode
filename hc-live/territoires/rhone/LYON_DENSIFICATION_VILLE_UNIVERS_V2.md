# HAUTE COUTURE LIVE — LYON — DENSIFICATION VILLE-UNIVERS V2

Référentiel : Nîmes = gabarit éditorial, jamais modèle culturel. Lyon doit être une grande ville pouvant soutenir des années de carrière sans redondance.

## 1 — IDENTITÉ JOUABLE

Lyon ne doit jamais être résumé à « soie + luxe ».

Identités simultanées :
- soierie / canuts / Jacquard ;
- design textile contemporain ;
- costume / théâtre / spectacle ;
- création indépendante ;
- vintage / seconde main ;
- industrie textile et innovation ;
- photographie / image / édition ;
- patrimoine / archives / recherche ;
- vie étudiante / écoles / jeunes créateurs ;
- clientèle urbaine quotidienne ;
- clientèle cérémonie / réception ;
- réseaux culturels et événementiels ;
- proximité Villeurbanne, Oullins, Caluire, Beaujolais ;
- circulation nationale et internationale par gare et aéroport.

## 2 — QUARTIERS / ZONES À TRAITER COMME MICRO-TERRITOIRES

### Croix-Rousse
Dominantes : canuts, tissage, ateliers, traboules, mémoire sociale, petites adresses créatives.
Gameplay : recherche textile, rencontres d’artisans, ateliers, archives, petites commandes, photographies, transmission.

### Presqu’île / Terreaux / Cordeliers / Bellecour
Dominantes : commerce, institutions, culture, événements, clientèle urbaine, image publique.
Gameplay : rendez-vous, commandes, presse, vitrines, achats, rencontres professionnelles, événements de centre-ville.

### Vieux Lyon / Fourvière
Dominantes : patrimoine, architecture, tourisme, cérémonie, photographie.
Gameplay : shootings, clients de passage, événements patrimoniaux, inspirations historiques, réceptions.

### Confluence
Dominantes : architecture contemporaine, design, événements, grands espaces culturels, image moderne.
Gameplay : éditorial, shooting, salons, événementiel, jeunes marques, vintage à La Sucrière.

### Guillotière / Jean Macé
Dominantes : diversité, commerces, jeunes actifs, ateliers, seconde main, vie quotidienne.
Gameplay : clientèle réelle du quotidien, tissus, retouches, petites commandes, rencontres moins prestigieuses mais très utiles.

### Part-Dieu
Dominantes : transport, commerce, flux, bureaux, clientèle professionnelle.
Gameplay : rendez-vous rapides, clientes pressées, voyages, achats, bouche-à-oreille professionnel.

### Gerland
Dominantes : grands équipements, événementiel, activité économique, studios/production à développer.
Gameplay : shootings, équipes techniques, commandes d’organisation, vêtements fonctionnels.

### Vaise / Industrie
Dominantes : reconversion industrielle, studios, production, jeunes entreprises.
Gameplay : ateliers, fabrication, photo/vidéo, petites séries, collaborations.

### Villeurbanne (pôle métropolitain voisin)
Dominantes : spectacle vivant, jeune création, population urbaine, culture contemporaine.
Gameplay : scène, costume, projets collectifs, commandes culturelles, réseaux étudiants.

## 3 — LIEUX RÉELS STRUCTURANTS

### Maison des Canuts
Fonctions :
- démonstration métier Jacquard ;
- chaîne / trame ;
- navette / canette ;
- cartons et mécanique Jacquard ;
- broché, brocart, velours ;
- histoire sociale des canuts ;
- industrie textile rhônalpine contemporaine.

Sorties possibles : TECHNIQUE_OBSERVED, MATERIAL_KNOWLEDGE, BOOK_RESEARCH, DESIGN_REFERENCE.
Jamais TECHNIQUE_LEARNED après une simple visite.

### Musée des Tissus
2026 : fermé pour travaux, collections circulant via prêts/dépôts.
Gameplay : monde changeant, recherche indirecte, exposition hors les murs, attente de réouverture, revisite plusieurs années plus tard.

### ENSATT
Fonctions documentaires : costume de scène, conception, moulage, technologie textile, patine, teinture, broderie, parures de tête, coupe en biais.
Gameplay : formation ou collaboration seulement si accès crédible ; pas de compétence gratuite.

### ENSBA Lyon — design textile
Fonctions : impression, ennoblissement, matériaux innovants, outils numériques, broderie, teinture, projets et recherche.
Gameplay : conférences, jurys, exposition de diplômés, collaborations, jeunes créateurs, stages/formation selon parcours.

### La Sucrière
Fonctions : grands événements, Marché de la Mode Vintage, salons, expositions.
Gameplay : vintage, sourcing, photographie, stands, réseau, événementiel.

### Opéra de Lyon / théâtres / scènes
Fonctions : spectacle, costume, habillage, équipes techniques, artistes de passage.
Gameplay : commandes, retouches urgentes, habillage, costume, relations professionnelles.

### Archives / bibliothèques / fonds locaux
Fonctions : canuts, commerce textile, urbanisme, photographie, presse, entreprises, histoire sociale.
Gameplay : BOOK_RESEARCH, secrets documentaires, pistes de collections, généalogie de lieux/ateliers.

## 15 — RÈGLE DE DENSITÉ POUR LES GRANDES VILLES

Une grande ville n’est validée que si elle possède au minimum :
- 6 à 10 micro-territoires/quartiers ;
- 25+ lieux/ressources catégorisés ;
- 30+ personnages persistants V1 ;
- 50+ briefs ;
- 15+ secrets/rumeurs ;
- 10+ familles événementielles ;
- 10+ types de clientèle ;
- sorties Atelier et Book spécifiques ;
- téléphone/agenda ;
- revisites ;
- évolution 20–30 ans.

Lyon V2 atteint ce seuil structurel et doit encore être enrichie en acteurs réels vérifiés sans transformer ces acteurs en PNJ scénarisés.
