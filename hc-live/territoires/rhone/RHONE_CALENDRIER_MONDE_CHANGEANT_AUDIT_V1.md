## Monde changeant 20–30 ans

### Lieux
- Musée des Tissus : travaux, circulation collections, réouverture future, nouvelle muséographie ;
- atelier ancien repris par jeune génération ;
- atelier qui ferme sans repreneur ;
- friperie qui change de quartier ;
- ancien local industriel transformé en lieu culturel ;
- école qui crée ou supprime un programme ;
- atelier partagé qui devient pépinière créative ;
- commerce de soie qui se spécialise davantage ou disparaît.

### Personnages
- étudiant → costumière / designer confirmé ;
- artisan → retraite → transmission ;
- cliente → mère → fille / fils client vingt ans plus tard ;
- journaliste → directrice de média ;
- technicien → producteur ;
- créatrice concurrente → collaboratrice ou organisatrice ;
- photographe débutant → référence régionale ;
- ancien mentor → figure patrimoniale.

### Événements
Chaque événement possède :
- un identifiant de famille ;
- une édition annuelle distincte ;
- un thème ;
- un niveau d’importance ;
- un lieu ;
- des partenaires ;
- des personnages présents ;
- des opportunités ;
- une mémoire des éditions déjà vécues.

États possibles : ACTIVE, ABSENTE, REDUITE, AGRANDIE, DEPLACEE, FUSIONNEE, RENOMMEE, RELANCEE, DISPARUE.
