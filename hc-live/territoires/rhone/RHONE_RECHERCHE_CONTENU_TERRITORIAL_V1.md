# HAUTE COUTURE LIVE — RHÔNE (69) — RECHERCHE & CONTENU TERRITORIAL V1

Référentiel de mise en forme : Nîmes ville test + checklist territoriale officielle + système événements évolutifs 2026→2056.

## Positionnement général

Le Rhône doit devenir l’un des territoires les plus puissants du jeu pour les axes suivants :
- soierie lyonnaise ;
- canuts ;
- tissage ;
- Jacquard ;
- rubans / façonnés / velours / brocarts ;
- costume de scène ;
- formation professionnelle ;
- design textile ;
- création contemporaine ;
- patrimoine industriel ;
- réseau culturel et professionnel ;
- mode / image / photographie / événementiel ;
- Beaujolais / réception / mariage / patrimoine / tourisme.

## Axes réels structurants

### Soierie / Canuts / Jacquard
La Maison des Canuts constitue une base réelle majeure pour comprendre :
- chaîne ;
- trame ;
- navette ;
- canette ;
- cartons ;
- mécanique Jacquard ;
- préparation du métier ;
- broché ;
- velours ciselé ;
- brocart ;
- histoire sociale des canuts ;
- évolution de la soierie lyonnaise.

### Costume / spectacle
L’ENSATT constitue un pôle réel exceptionnel pour les métiers du costume :
- atelier costume ;
- conception costume ;
- histoire du costume ;
- technologie textile ;
- moulage ;
- patine ;
- teinture naturelle ;
- broderie ;
- parure de tête ;
- gestion du costume de scène ;
- coupe en biais.

Règle : Marion ne reçoit jamais ces compétences gratuitement. Les contenus réels servent de justification à une progression lente, conditionnée par niveau de carrière, formation, relations, stages ou collaborations.

### Musée des Tissus
En 2026, le musée est fermé pour travaux mais ses collections restent actives via prêts et dépôts. Ce statut est parfait pour le moteur de monde changeant :
- fermeture ;
- travaux ;
- circulation des œuvres ;
- réouverture future ;
- nouveaux accrochages ;
- redécouverte par Marion plusieurs années plus tard.

## Identités de gameplay

### Lyon
Textile, soie, costume, scène, luxe, patrimoine, design, photographie, écoles, culture, industrie, mode et réseau pro.

### Villefranche / Beaujolais
Réception, mariage, clientèle événementielle, tourisme, patrimoine, image, photographie, réseau d’entrepreneurs, saisonnalité viticole et festive.

### Tarare
Patrimoine textile / industriel à documenter finement ; potentiel très fort pour voilage, textile de maison, production et mémoire ouvrière.

### Villeurbanne
Culture contemporaine, spectacle, création, jeunes réseaux, studios, population urbaine et croisements avec Lyon.

### Monts du Lyonnais
Petite production, artisanat, clientèle de proximité, paysages, mariage, ruralité contemporaine, revisites et transmission.

## Règle événementielle
2026 sert uniquement de base documentaire. Toute édition 2027–2056 est générée comme une édition distincte : thème, lieu, partenaires, participants, opportunités, conséquences et accès peuvent évoluer.

## Sorties Atelier possibles
- TECHNIQUE_OBSERVED : tissage Jacquard, construction costume, moulage, patine, teinture, broderie, parure ;
- TECHNIQUE_LEARNED : uniquement si formation / atelier / accompagnement crédible ;
- MATERIAL_KNOWLEDGE : soie, fils métalliques, tissus façonnés, velours, rubans, textiles techniques ;
- DESIGN_REFERENCE : canut, traboule, architecture Croix-Rousse, théâtre, patrimoine industriel ;
- CRAFT_CONTACT : tisseur, costumier, brodeur, teinturier, créateur textile ;
- COLLAB_CAPABILITY : développement avec atelier textile ou costume ;
- BOOK_RESEARCH : archives, collections, expositions, prototypes, coulisses de scène.

## Règles absolues
- réel ≠ personnage interactif automatique ;
- vrai professionnel ≠ mentor / client / employeur automatique ;
- personnage fictif-pont pour les arcs scénarisés ;
- aucune visite ne donne une maîtrise complète ;
- aucune édition d’événement ne doit se rejouer à l’identique ;
- Lyon doit être dense mais pas obligatoire dans toutes les carrières ;
- vivre dans un petit territoire du Rhône reste aussi valide que vivre à Lyon.
