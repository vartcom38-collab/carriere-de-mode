## Anti-redondance
Avant de générer un brief, comparer au minimum :
- famille de mission ;
- matériau principal ;
- personnage ;
- lieu ;
- niveau de carrière ;
- saison ;
- événement source ;
- type de silhouette ;
- conséquence relationnelle ;
- conséquence Book/Atelier ;
- délai ;
- budget ;
- dernière occurrence similaire.

Si similarité trop élevée : changer au moins 3 dimensions ou supprimer la mission cette année.
