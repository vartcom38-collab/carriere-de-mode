# 3 — MODÈLE D’ÉVOLUTION DES ÉVÉNEMENTS

Chaque famille d’événement possède :
- `eventFamilyId` ;
- `editionYear` ;
- `theme` ;
- `scale` ;
- `venue` ;
- `participants` ;
- `audienceProfile` ;
- `fashionHooks` ;
- `historyMemory` ;
- `status` = stable / growing / shrinking / paused / moved / merged / ended / revived.

### Exemple — Tisséade
2026 : salon tissus/mercerie large.
2028 possible : orientation plus forte vers eco-matières.
2030 possible : déménagement / format réduit.
2034 possible : retour avec forte dimension machines numériques.
2038 possible : aucun enjeu direct pour Marion.
2044 possible : invitation comme intervenante.

### Exemple — Origine Loire
Une année peut favoriser artisanat ; une autre innovation ; une autre emploi/formation ; une autre fois le textile peut être moins central.
