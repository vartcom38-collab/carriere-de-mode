# HAUTE COUTURE LIVE — SAINT-ÉTIENNE — CHECKLIST VILLE V1

Format : gabarit Nîmes.

---

# 1 — ADN

Saint-Étienne doit être un grand pôle de carrière fondé sur :
- rubanerie ;
- passementerie ;
- industrie ;
- design ;
- innovation ;
- textile technique ;
- culture ouvrière ;
- création contemporaine.

La ville ne doit pas être réduite à un décor industriel : elle doit proposer recherche, fabrication, design, culture, réseau, scène, photo, clientèle et transformation urbaine.

---

# 2 — PÔLE TEXTILE MAJEUR

Le Musée d’Art et d’Industrie conserve ce qui est présenté comme la première collection mondiale de rubans.

La rubanerie stéphanoise existe depuis plusieurs siècles et relie mode, lingerie, sport, santé et usages techniques.

Collections et techniques exploitables comme recherche :
- rubans unis ;
- brochés ;
- velours ;
- jacquard ;
- images tissées ;
- mise en carte ;
- métiers anciens et modernes ;
- rubans haute couture ;
- textiles techniques.

RÈGLE : observer un métier ne signifie pas savoir le conduire professionnellement.

---

# 3 — SORTIES ATELIER

Possibles :
- TECHNIQUE_OBSERVED : structure du tissage étroit ;
- MATERIAL_KNOWLEDGE : comportements du ruban ;
- DESIGN_REFERENCE : rythmes, bandes, répétitions, bordures ;
- MOTIF_REFERENCE : motifs tissés ;
- CRAFT_CONTACT : passementier / technicien FICTION GAMEPLAY ;
- COLLAB_CAPABILITY : commande de ruban spécifique ;
- BOOK_RESEARCH : archive textile / industrie / haute couture.

Pas de maîtrise automatique du Jacquard ou de la production industrielle.

# 8 — PREMIÈRE BANQUE DE 20 BRIEFS

1. Intégrer un ruban industriel dans une pièce sans effet décoratif gratuit.
2. Transformer un lot de rubans anciens en accessoires contemporains.
3. Créer un détail fonctionnel pour une tenue de sport.
4. Imaginer une ceinture à partir d’un principe de textile étroit.
5. Tenue pour une médiatrice culturelle.
6. Shooting autour de métiers et machines.
7. Pièce inspirée d’une mise en carte historique.
8. Accessoire de scène visible à distance.
9. Collaboration avec un passementier FICTION GAMEPLAY.
10. Réinterprétation d’un motif floral de ruban.
11. Capsule noir/industrie/design.
12. Prototype nécessitant une résistance technique précise.
13. Petite série pour un événement design.
14. Tenue de présentation pour une entrepreneuse textile.
15. Projet commun avec une ingénieure matière.
16. Pièce haute couture construite autour de bandes tissées.
17. Costume de performance intégrant mouvement et tension.
18. Projet d’archive + création contemporaine.
19. Résidence design/mode interdisciplinaire.
20. À haut niveau de carrière, commande manifeste liant industrie et couture.

# 9 — SECRETS / RUMEURS

- ancien stock dormant ;
- carnet de motifs ;
- atelier peu visible ;
- ancien technicien connaissant une méthode abandonnée ;
- prototype industriel jamais commercialisé ;
- collection privée de rubans ;
- jeune entreprise travaillant une application inattendue ;
- lieu de production reconverti ;
- commande passée par recommandation uniquement.

# 11 — CARRIÈRE LONGUE

Début : musée, recherche, petites retouches, découverte du ruban.
Développement : collaboration avec artisans/techniciens, photo, petites séries.
Confirmée : commandes professionnelles, design, scène, collaborations industrielles.
Avancée : résidences, jurys, transmission, projets de patrimoine industriel, création manifeste.

# 12 — MONDE CHANGEANT

- entreprises qui ferment / fusionnent / innovent ;
- ateliers transmis ;
- nouveaux textiles techniques ;
- anciens procédés redécouverts ;
- quartiers créatifs qui évoluent ;
- musées qui changent d’exposition ;
- anciennes relations qui deviennent directeurs, acheteurs ou enseignants ;
- une jeune créatrice peut devenir concurrente majeure vingt ans plus tard.

Saint-Étienne doit être une ville où Marion comprend que l’innovation mode peut naître d’un territoire industriel autant que d’une capitale de mode.
