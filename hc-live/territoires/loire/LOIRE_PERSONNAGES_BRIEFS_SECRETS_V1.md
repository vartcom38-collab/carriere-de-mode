# 8 — ANTI-REDONDANCE

Avant de générer une mission, comparer :
- famille de brief ;
- territoire ;
- lieu ;
- client ;
- matière ;
- technique ;
- enjeu ;
- saison ;
- récompense ;
- personnages impliqués.

Si similarité trop forte avec une expérience récente, changer au moins trois dimensions ou ne générer aucune mission.

Les événements annuels peuvent exister sans produire systématiquement une commande pour Marion.
