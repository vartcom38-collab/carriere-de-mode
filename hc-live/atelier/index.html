Pourquoi ce test ?

On change enfin de méthode : comme pour la carte, l’Atelier s’appuie maintenant sur un vrai moteur spécialisé au lieu de fabriquer nous-mêmes toutes les fonctions graphiques.

  • OpenClo est open source sous licence MIT.
  • Il tourne dans le navigateur avec WebGPU / WASM.
  • Il propose des outils de patron, couture, tissu et visualisation 3D.
  • Ce premier test sert à valider le moteur ; l’interface Fashion Sketch de notre jeu viendra ensuite autour.
