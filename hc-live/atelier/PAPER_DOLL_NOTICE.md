# Paper Doll Studio attribution

The Atelier paper-doll layer architecture and temporary aligned demo assets reference the open-source project **Paper Doll Studio** by Paper Doll Studio Contributors:

https://github.com/Khurramali1997/paper-doll-studio

Paper Doll Studio is licensed under the Apache License 2.0. The source repository describes a 768×768 aligned-layer renderer, wardrobe slots, z-order, per-garment generation and game-ready wardrobe asset export.

Changes in Haute Couture Live: the original editor is not embedded wholesale. A separate browser-side wardrobe core was written for the game and connected to Haute Couture Live's own materials, missions, time, money, saving and UI. Temporary demo layer image URLs point at the upstream Apache-2.0 sample assets while the game's own fashion-specific asset library is developed.
